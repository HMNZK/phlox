# Handoff: Phlox macOS UI 再構築

## 概要
Phlox は、複数の AI コーディングエージェント（Claude Code / Codex / Cursor / agents.json のカスタム）を 1 つのウィンドウで同時に動かし、監視・指示・承認する macOS アプリ。このパッケージは、現行 UI の機能一覧（`reference/ui-feature-inventory.md`）を要件として UI を 0 から再設計した結果をまとめたもの。

設計の中心は「どのセッションが自分の対応を待っているかを即座に知る → 許可・回答・追加指示を返す → 次へ」を、マウスでもキーボードだけでも最短で回せること。

## デザインファイルについて
`designs/` の `.dc.html` は **HTML で作ったデザイン参照（モック）** で、製品コードではない。やることは、これらの見た目と振る舞いを **既存の Phlox コードベース（SwiftUI / AppKit、DesignSystem パッケージ）の流儀で作り直す** こと。HTML をそのまま組み込まない。

- 開き方: `designs/` をフォルダごと置き、任意の番号付きファイル（例: `01 Main Window.dc.html`）をブラウザで開く。`support.js` と `Phlox*.dc.html`（部品）が同じフォルダに必要。
- 各ページはキャンバス（パン・ズーム可）。見本には `A1` `S3` のような ID が付いており、README とプロンプトはこの ID で参照する。
- アイコンは線画・頭文字で代用している。実装では SF Symbols と既存の `AgentBrandIcon` を使う（`12 Design System` のアイコン表）。
- 画像の枠（縞模様）は、既存の実装（圧縮中の犬アニメーション、ThinkingOrb、アプリアイコン）を差し込む場所。

## 忠実度
**高忠実度（hi-fi）**。色・文字・余白・状態の出し分け・文言は確定値として扱う。ただし、各ページの「分岐候補」「案」「要確認」と書かれた箇所は仕様が確定していない（下の「未確定事項」）。

## 全体の決定事項（画面をまたぐもの）
1. **ウィンドウ構成**: サイドバー（既定 260pt、220–360）｜中央（単体 / グリッド）｜インスペクタ（右端、既定 280pt、260–340）。右端のドロワーは廃止し、中央のタブに統合（02 C）。
2. **タブ（02 C）**: 上段 = プロジェクトのセッションのタブ。下段 = そのセッションの子タブ（会話・ターミナル・変更・ファイル）。ターミナルとファイルはセッションの worktree で開く。設定 / エージェント管理はウィンドウ共通のタブとして上段右端。タブの並びと分割はプロジェクトごとに保存。
3. **対応待ち**: 承認待ち・質問待ち・エラー・無応答の 4 状態の総称。完了の未読は含めない。入口はツールバーの「対応待ち n」（一覧ポップオーバー）、サイドバー最上部、Dock バッジ、⌘J。
4. **状態の表示**: 一覧（サイドバー・タイル）はアイコンを使わず文字で出す。色が付くのは対応待ちの 4 状態だけ（琥珀・青・赤・紫）。実行中・待機・完了は無彩色。点滅は廃止。
5. **承認**: ボタンは「許可 / このセッション中は許可 / 拒否 / キャンセル」。カードの先頭に許可の対象（コマンド全文・ファイル・権限ルール）。入力欄にいるときは ⌥⌘↩ / ⌥⌘⌫、カードにフォーカスすると Y / S / N / Esc。表示直後 0.5 秒は押せない。フォーカスを自動で移さない。
6. **選択と範囲**: サイドバーのプロジェクト行クリック＝選択＝グリッドの表示範囲（「選択」と「絞り込み」の状態を統合）。
7. **削除系**: グリッドのタイルの ✕ は「外す」（削除しない）。取り返しがつかない操作の確認は既定ボタンをキャンセルにする。
8. **チームビュー（6 章）と討論設定（phlox.agora.*）は削除**。

## 未確定事項（実装前に確認）
- **13 章 エージェント管理ウィンドウは未設計**。当面は現行 UI を維持し、トークンと部品だけ新デザインに揃える。
- ⌘W と ⌘1–9 の割り当て（タブ採用時に決定。ユーザー確認待ち）。
- カードの既定の開き方のうち「案」の行（推論・コマンド単体・タスクリスト）。
- completed(exitCode) のチャット型での意味（04 B3）。
- 「このセッション中は許可」の範囲、「キャンセル」がターンも止めるか（05）。
- 画像添付の可否（05 R8 案 A〜C。機能一覧 16.5 の不整合）。
- オーケストレーションの子セッションをサイドバーに出すか（03 G3）。
- 通知から直接「許可」するか（11 N1 / N1b）、対応待ちの通知音。
- Dock バッジの数え方の設定、「匿名の利用状況を送信」、APNs / トークン再発行の UI（10）。
- Claude 使用量の鮮度の閾値、使用量バケット名（07）。
- worktree のパス規則、モデル・権限の初期値の出どころ（08）。
