承認バナーは会話の中ではなく入力欄の直上に固定する（最下部に 1 枚だけ）。種類ごとに見出しを変える: 「承認待ち · コマンドの実行」「承認待ち · ファイルの変更」「承認待ち · 権限の変更」（返答エリアの回に合わせて統一）。選択肢は 許可 / このセッション中は許可 / 拒否 / キャンセル の 4 つ。
思考中インジケータは、ThinkingOrb（6 モード）の代わりに点線の円で示した。文言は活動の状態（考え中・検索中・実行中・編集中・書き込み中・待機中）に合わせて変え、下の行に直近のアクションの要約を出す。

B. 状態の描き分け
B1実行中 · ツールが連続実行されている
実行中のグループだけが開き、枠線が 1 段濃くなる。推論は 1 行のプレビューだけ。入力欄の右端は中断ボタン（Esc / ⌘.）。
B2待機 · ターンが終わり次の指示待ち（ダーク）
B3完了 · プロセスが終了した
分岐候補: completed(exitCode) がチャット型でどの場面を指すかは未確認。プロセス終了と解釈し、入力欄の代わりに終了コードと「この会話から再開」（Claude / Codex の再開機能）を出した。
B4エラー · ビルド失敗と API エラー
失敗したコマンドは開いたままにし、エラー行を赤で示す。エラーのセルは赤の枠＋三角＋見出しの 3 つで示す。
B5無応答 · 120 秒反応なし（ダーク）
思考中インジケータが紫の枠に変わり、経過時間（1 秒ごとに更新）と「中断」を出す。ヘッダの状態も「無応答 2:14」。検知はチャット型だけで、ターミナル型には出ない。
B6圧縮中 · /compact
B7非常に長い会話 · 過去を読んでいて追従が外れている
最初は直近だけを描画し、先頭の「以前のメッセージを表示」で読み込む範囲を広げる。手動で最下部から 80pt 以上離れると追従を外し（新着でスクロールしない）、「↓ 最新へ · 新着 n」を出す。押すか、会話にフォーカスがあるときの End で最下部に戻り、追従を再開する。セッションを切り替えると追従状態は戻る。
C. 操作の流れ
C1ホバー（コピーと時刻）とテキスト選択
本文・コード・コマンド出力は選択できる。差分の行は選択できないので（セッション切替が最大 1987ms 遅くなる原因だったため）、代わりに「セクションをコピー」を出す。
C2カードを展開（グループ・差分・コマンド）
C3サブエージェントのドロワー（帯かマーカーをクリック）
右に 42%（最小 320pt・最大 60%、幅は保存）で開く。本文の上に推論の末尾 3 行を出し、下端から追加の指示を送れる。Esc・✕・「メインへ戻る」で閉じる。帯の同じチップをもう一度押しても閉じる。
C4Esc を 2 回（1.5 秒以内）→ 巻き戻し
Esc 1 回の優先順: ① このピッカーを閉じる → ② サブエージェントのドロワーを閉じる → ③ 実行中なら中断。2 回でピッカー。確定すると、選んだ発言が入力欄に戻る。
C5過去の会話から再開（新規セッションの最初）
Claude Code と Codex だけ。選ぶと会話の中身をそっくり置き換える。Cursor では出さず、すぐに空の会話から始める。
C6会話を書き出す（ヘッダのボタン / ⇧⌘E）
推論・コマンド出力・タイムスタンプの有無を選ぶ。選択はアプリ全体で覚えておく。書き込みに失敗したらアラートを出す（現行どおり）。
