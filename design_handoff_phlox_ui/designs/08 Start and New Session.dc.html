空の画面と新規セッション
中央に何も表示していないときの 3 つの状態（プロジェクト 0 件 / 未選択 / プロジェクトだけ選択）と、どの入口から始めても同じ手順で進む新規セッションの作成。
作成の手順（全入口で共通）
① 種別と開き方入口ごとの UI で選ぶ。起動中は全入口を無効にする（多重起動の防止）
② CLI の確認見つからない種別は選べない状態で見せる（S3）
③ 作業ディレクトリの衝突同じディレクトリで動いているセッションがあれば確認する（F1）
④ worktree隔離がオンなら 作成 / 再利用 / 作り直し / 中止 のどれかになる（F2〜F4）
⑤ 起動成功したらプロジェクトを開き、単体表示で選択する。失敗はアラート（F5）
③と④は確認が必要なときだけ出す。再利用と「隔離オフ」のときは何も出さずに起動する。
S. 何も選ばれていないとき
S1初回起動（プロジェクト 0 件）
サイドバーは Sidebar S3（空）と組み合わせる。検出の結果を先に見せ、使えない種別があっても始められることを示す。2 回目以降でプロジェクトを全部消した場合は、手順 2・3 を省いた 1 だけを出す。
S2プロジェクトはあるが何も選んでいない（ダーク）
S3起動カード · CLI が未インストールの種別がある
カードは隠さず、淡くして理由と「入手方法」「再検出」を出す。構造化チャットに対応しないカスタム種別は「ターミナル」だけを出し、それを主ボタンにする。
S4起動カード · 全種別が使える（ダーク）
S5狭い幅では 2 列に · 起動中（worktree を作成中）
F. 確認とガードレール
F1同じ作業ディレクトリを共有するセッションとの衝突
worktree 隔離がオフのプロジェクトでだけ出る（オンなら④に進むので衝突しない）。同じディレクトリで動いているセッションを状態付きで並べ、既定の選択は「worktree で分けて起動」にする。
F2worktree の作成（確認なし・進行を表示）
作成・再利用は確認を出さない。下端に作業ツリーのパスを出し、終わったら消す。
F3worktree の作り直し
F4worktree の作成に失敗（中止）· ダーク
git の出力をそのまま見せ、次の手（既存の worktree を使う / 隔離なしで起動 / やめる）を並べる。
F5起動の失敗（例: 子セッションの深さ上限）
同じ形で出す失敗: CLI の実行ファイルが見つからない / カスタムのバイナリが見つからない / 深さ上限（3）/ 総数上限 / レート上限（1 秒に 5 回）/ hooks を設置できない（既存の設定ファイルと衝突）/ 後始末の失敗（警告）。文言は Localizable の既存キーを使う。
