## A. コード境界ケース

撮影名は各行の `t47-{組}-code-<slug>.png`。0 空白の AXStaticText 値は `\t  **x  \n`、末尾空行も同じ可視テキストであることを確認した。タブ・空白は画面上では空白幅としてだけ見え、文字画像からタブ文字そのものや行末空白の個数は区別できない。

|ボタン / slug|画面・AX の文字列レベルの観測|
|---|---|
|`0空白` / `zero-space`|`swift` コードカード内に `**x`。前置タブ・2 空白と末尾2空白は AX 値に残る。`**` は装飾化されず可視。|
|`3空白` / `three-space`|`swift` コードカード内に `**x`。`**` は可視のまま。|
|`4空白` / `four-space`|カード見出しは「コード」。本文に `````swift``, `**x`, ````` がそのまま表示され、フェンスはコード内容として可視。|
|`タブ` / `tab`|コードケースとして表示され、`**x` は装飾化されず文字列として残る。|
|`3本` / `three-backticks`|コードカード本文は `a`。開始・終了の3バッククォートは本文には表示されない。|
|`4本` / `four-backticks`|コードカード本文は `a`, ` ``` `, `b`。外側の4バッククォートは本文には表示されないが、内側の3バッククォートは可視。|
