# ADR 0034: モバイルのターミナル出力は Mac と同じエンジン（SwiftTerm）で描く

> **一部が覆されている**: 決定 2・3・7（横スクロール / Mac の桁数を守る / トグルに畳む）は
> [ADR 0035](0035-mobile-terminal-fits-screen-width.md) が置き換えた。決定 1・4・5・6 は生きている。

> **このファイルの役割**: 「出力」カードを等幅テキストの羅列から実際の端末描画へ替えた決定と、桁・高さ・配色の決め方。
> **書かないもの**: Mac が色つき画面を配信する仕組み（→ [macos/docs/adr/0126](../../../macos/docs/adr/0126-output-endpoint-serves-ansi-screen.md)）、本文の折り返し方針（→ [ADR 0031](0031-chat-body-readability-wrapping-and-table-scroll.md)）。

## 文脈

デスクトップのターミナルセッションをモバイルで開くと、「出力」の見出しとトグルの中に色のない文字列が並ぶだけで、Mac の画面とは似ても似つかなかった（ユーザー報告: 「デスクトップアプリのターミナル画面と同じように表示させて欲しい」）。原因は配信側が色を落としていたこと（ADR 0126 で解決）と、表示側が `Text` に等幅フォントを当てていただけだったこと。

## 決定

**Mac が配信する ANSI 画面を、Mac と同じ SwiftTerm で描き直す。**

1. **SwiftTerm 依存を `TerminalScreenIOS` ターゲットへ閉じ込める**。Mac 側 `TerminalUI` と**同じ vendored fork** を参照するので、エスケープの解釈が食い違わない。`Features` は View だけを使う。
2. **読み取り専用**。`isUserInteractionEnabled = false` でキーボード・カーソルを出さず、横スクロールは親の `ScrollView` に委ねる。カーソルは `ESC[?25l` で消す。
3. **桁数は Mac のものをそのまま使う**。本文は Mac の桁で折り返し済みなので、狭く描くと二重に折り返す。SwiftTerm の内部セル寸法は非公開なので、同じフォントで同じ式（`"W"` の幅と ascent+descent+leading の切り上げ・ピクセルグリッド丸め）を再現し、**2桁ぶん多めに**確保する。広い分には害がない。
4. **高さは本文の行数で決める**。Mac の端末は常に一定の高さ（例: 24行）を持つが下は空行のことが多く、そこまで確保すると巨大な黒帯になる。配信側が末尾の空行を落として送ってくるので、本文の行数が実際の中身の高さになる。
5. **配色は Mac の `TerminalPalette.phloxDefault` を複製して持つ**。運ばれてくるのは「どの ANSI 色か」であって RGB ではないため、同じパレットを両側で持たないと色がずれる。`TerminalUI` は AppKit 依存で iOS から import できないので値を複製している。**片方だけ変えるとずれる。**
6. **色つきで来なかったときは従来の等幅テキストのまま**。端末を持たない構造化セッションや、古い Mac に繋いだ場合に画面が壊れない。
7. **折りたたみ判定・空判定はエスケープを除いたプレーンテキストで行う**。既存の「12行を超えたら畳める」規則がそのまま効く。

## 棄却案

- **ANSI を自前で解析して `AttributedString` にする**: SwiftTerm 依存を避けられるが、解釈が Mac とずれる余地が残る（全角・結合文字・属性の重なり）。「同じ見た目」が要件なので同じエンジンを使う。
- **PTY の生バイト列をモバイルで再生する**: 途中から再生するとエミュレータ状態が Mac と一致せず化ける（ADR 0126 の棄却案と同じ理由）。
- **画面幅に合わせて桁数を詰める / フォントを縮める**: 折り返し位置が Mac と変わるので TUI の枠線・表が崩れる。桁は守り、横スクロールで読ませる。
- **Mac の端末高さぶんの領域を確保する**: 忠実ではあるが、モバイルでは空の黒帯が画面を占領して本文が読めない。

## 結果

- iOS シミュレータで実描画を確認した（緑の `›`、太字の黄色 `OK`、行頭からの描画、カーソル非表示、内容ぶんの高さ）。
- `TerminalScreenIOSTests` 7 件・`TerminalScreenTests` 6 件を追加し、PhloxKit 569 件が green。
- **未検証**: 実際のエージェントセッション（Claude Code / Codex の TUI）を実機で表示した見た目。モックの短い画面でしか確認できていない。TUI の枠線・全角・256色の再現はユーザーの実機確認待ち。
- Mac 側を再起動しないと `format=ansi` を返せないので、モバイルだけ更新しても色は付かない。
