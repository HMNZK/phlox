# ADR 0036: セッション一覧の大タイトルはシステムに任せず本文の先頭に自分で描く

> **このファイルの役割**: iOS 26 で「Projects」が消える不具合の原因と、大タイトルを自前描画へ移した決定。
> **書かないもの**: ナビゲーションバーの配色（→ [ADR 0014](0014-navigation-chrome-appearance-idempotent-install.md)）、セッション詳細の chrome（→ [ADR 0033](0033-session-detail-uses-system-navigation-bar.md)）。

## 文脈

実機（iPhone 14 Plus / iOS 26.5.2）で「Projects が一瞬だけ表示されてすぐ消えます」という報告が続いた。バーの高さだけが残り、文字だけが消える。

原因の特定に時間がかかったのは、**手元で再現できなかったから**である。再現しなかった理由は 2 つあった。

1. **OS バージョン**。手元のシミュレータは iOS 18.3.1 で、この症状は **iOS 26 でしか出ない**。
2. **モック環境**。`-UITesting` では一覧の状態を固定し（`seedStateForUITesting`）ポーリングを止めているうえ、`AppRoot` が 1ms 間隔で再取得を回すため画面が絶えず作り直され、症状が打ち消される。

iOS 26.2 のシミュレータへローカル偽サーバー（`ios/scripts/fake-phlox-server.py`）を live 接続して、ようやく決定論的に再現した。**引き金は一覧のスクロール**で、下へスクロールして最上部へ戻すと、システムの大タイトルは二度と戻らない。中身・データ更新・タブバー・我々のバー配色のいずれとも無関係で、`ScrollView` に `Text` を並べただけの画面でも起きる。

さらに厄介なことに、**消えているのは描画だけ**でアクセシビリティ要素と枠は残る。`exists` / `isHittable` / `frame` はすべて健全な値を返すため、XCUITest の通常のクエリでは検出できない。

## 決定

**大タイトル「Projects」を `navigationTitle` + `.large` に任せるのをやめ、スクロール内容の先頭に `Text` として自分で描く。**

1. **バーは `.inline` にし、`navigationTitle` は「Projects」のまま残す**。バーの同一性（`app.navigationBars["Projects"]`）が保たれ、既存の遷移テストがそのまま効く。
2. **バーに出す小さいタイトルは、大タイトルが隠れている間だけ出す**。`onScrollGeometryChange` でスクロール量を見て切り替え、最上部では空にする（二重に出さない）。
3. **スクロールしない状態（読み込み中・空・オフライン・エラー）でも同じ位置に置く**。状態によってタイトルの有無が変わらないようにする。
4. **回帰テストは画素で判定する**。要素の有無では検出できないため、`XCUIScreen.main.screenshot()` からタイトル範囲を切り出して、実際に描かれた画素数がスクロール前後で保たれることを確かめる。
5. **その回帰テストは通常のスイートから外す**（`SessionListTitleLiveRegressionUITests`）。モック環境では再現しないので、偽サーバーへの live 接続が要る。手順はテストの doc コメントに書いた。

## 棄却案

- **iOS 26 の挙動を待つ / 回避策を入れない**: ユーザーが実際に使えない。
- **`List` へ置き換える**: システムの大タイトルは正しく動く可能性があるが、一覧のカード表現・`DisclosureGroup` の見た目を作り直すことになり、影響が大きすぎる。
- **iOS 26 のときだけ自前描画に切り替える**: 分岐が増え、iOS 18 側の経路がテストで踏まれなくなる。挙動は両方で同じにしたい。
- **`navigationTitle` を空にしてバーを空にする**: 大タイトルは出せるが、`app.navigationBars["Projects"]` が解決できなくなり、既存の遷移テスト十数件が「一覧に居るか」を判定できなくなる。
- **アクセシビリティ要素の有無で回帰テストを書く**: 実際に試したが、消えていても要素は残るため**素通りする**（pass してしまう）。テストとして意味がない。

## 結果

- iOS 26.2 シミュレータでスクロール往復しても大タイトルが残ることを確認した。回帰テストは修正前のコードで fail（前=12176 画素 → 後=0 画素）、修正後に pass する。
- iOS 18.3.1 / iOS 26.2 の両方で `PhloxMobileUITests` 26 件が green。見た目は iOS 18 で従来とほぼ同じ。
- **副作用**: スクロール中にバーへ出る小さいタイトルは、我々のバー配色（`.toolbarBackground(.visible)` / `.toolbarColorScheme`）を当てている間、iOS 26 では表示されないままである（切り分け中に判明）。今回の修正の範囲外として残す。
- **未検証**: 実機（iOS 26.5.2）での確認。シミュレータ（iOS 26.2）でしか確認していない。
