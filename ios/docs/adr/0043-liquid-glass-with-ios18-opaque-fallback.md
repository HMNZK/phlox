# ADR 0043: Liquid Glass を採り、iOS 18 は同じ配置を不透明に描く

> **このファイルの役割**: iOS 再設計（2026-10）で見た目の土台を Liquid Glass にし、配布対象の iOS 18 では同じ配置の不透明な描き方にした決定と、分岐の置き場所。
> **書かないもの**: 部品ごとの見た目（→ [specs/redesign-2026-10.md](../specs/redesign-2026-10.md) 2.6）、作業の順（→ [delivery/0020](../delivery/0020-ios-redesign-plan.md)）。

## 文脈

再設計の見本（`ios/docs/specs/ClaudeDesign/`、版 241）は、2 回目の改訂で不透明なバーの案（ShellSolid・DetailSolid）を捨てて Liquid Glass（iOS 26）に一本化し、iOS 18 での見え方を `Shell18`・`Detail18` に残した。アプリの配布対象は iOS 18.0（ADR 0025）で、下げない。

## 決定

1. **iOS 26 では OS の Liquid Glass を使う。** タブバー・新規チャットの丸・対応待ちバー・入力欄・承認と質問のカード・ナビの丸ボタン・メニューだけをガラスにし、行・カード・会話・ダイアログの中身はガラスにしない（見本 `DS` の「ガラスは操作の層だけ」）。ガラスを自前の半透明とぼかしで似せない。
2. **iOS 18 は同じ配置で不透明に描く。** 部品の場所・大きさ・文言は変えず、材質だけを `Shell18`・`Detail18` の描き方（素材の帯・1pt の線・ナビの丸ボタンは印だけ）にする。新規チャットだけは置き場所が変わる（一覧の大見出しの右）。
3. **分岐は共通の部品 1 か所に閉じ込める。** `#available(iOS 26, *)` は段階 1 で作るガラスの部品（バー・ボタン・カードの面）の中だけに書き、画面のコードには書かない。

## 棄却案

- **iOS 26 に上げる**: 配布対象を変えると iOS 18 の利用者が使えなくなる。
- **不透明の案に戻す（両 OS で同じ見た目）**: 見本が 2 回目の改訂で捨てた案。iOS 26 で OS の部品（シート・メニュー）だけがガラスになり、自前のバーと材質が揃わない。
- **画面ごとに `#available` で分ける**: 分岐が散らばり、iOS 18 の描き方が画面ごとにずれる。

## 結果

- iOS 18 の見た目は `Shell18`・`Detail18` の 2 枚と `DS` 7 章の表が根拠になる。それ以外の画面の iOS 18 版は描かれていないので、共通の部品の規則から作る。
- 手元の Xcode と iOS 26 SDK で使える Liquid Glass の API は、段階 1 の最初に確かめる（計画書 7 章）。iOS 18 のシミュレーター（ランタイム 18.0・18.3）は入っているが、端末は作っていない（2026-10-17 時点）。
- タブバーを OS 標準の `TabView` にするか自前のまま材質だけ変えるか（ADR 0006 の見直し）は、段階 3 で API を確かめて決める。
