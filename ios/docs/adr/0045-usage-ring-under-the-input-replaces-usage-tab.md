# ADR 0045: 使用量タブをやめ、入力欄の下の残りのリングで見せる

> **このファイルの役割**: アカウントの使用量（CLI の枠の残り）の置き場所を、独立したタブから入力欄の下の 1 行へ移した決定と理由。
> **書かないもの**: リングの見た目・状態・読み上げ（→ [specs/redesign-2026-10.md](../specs/redesign-2026-10.md) 7 章）。ワイヤは `GET /usage`（契約 §7.4）のまま。

## 文脈

今の下部タブは「セッション」「設定」「使用量」の 3 つ（ADR 0007）。使用量は枠の残りを見たいときにだけ開く画面で、指示を送る直前に「あとどれだけ使えるか」を知る場所から遠い。見本は 1 回目で一覧の下端のバー、2 回目（5/6）で入力欄の下の 1 行に移した。

## 決定

1. **使用量のタブ・画面・設定の区画を消す。** タブは「セッション」「設定」の 2 つにする。`Features/Usage/UsageView.swift` と関連テストは段階 1 で消す。
2. **新規チャットとセッション画面の入力欄の下に、エージェントごとの枠の残りのリングを 1 行で出す。** 数値は押したときの吹き出しで出す。行全体を 1 つのボタンにし、VoiceOver は行を 1 つとして読む。
3. **残り 20% 未満だけを注意の色（`status.caution`）にする。** 「上限間近」「上限に達しました」の文言はやめる。実際に取得できた既知の枠だけを表示し、値が無い枠や取得できないエージェントは隠す。0% は取得済みの有効な値として表示する。

## 棄却案

- **一覧の下端のバー**（見本 1 回目）: タブバー・対応待ちバーと下端を取り合い、一覧を見ているときにしか目に入らない。
- **設定の中の区画**: 開く手間はタブと変わらない。
- **数値を常に出す**: 3 エージェント・6 枠の % が入力欄の下に並び、狭い画面で 1 行に収まらない。

## 結果

- ADR 0007 の「sessions/settings/usage の 3 タブ」はこの ADR で 2 タブに置き換わる（overview を消した決定は有効）。
- `AppRoot` にアプリ全体で共有する `UsageViewModel` を 1 つ置く。入力欄のある画面を開いたとき・アプリが前面に戻ったとき・一覧の引っ張って更新で取得し、3 秒ごとの一覧更新には含めない。
- 初回取得前と有効な枠が 0 件のときは行を出さない。エージェントは `state == ok` かつ少なくとも 1 つの既知枠の値がある場合だけ表示し、枠も実際に返った既知枠だけを表示する。値 0% は有効値として残す。全体の取得に失敗したら古いリングを消し、次の取得に成功したら有効な値から再表示する。取得中は直前の有効値を保つ。リング・詳細・VoiceOver は同じ絞り込み済み投影を使う（仕様書 U-7）。
- 使用量行はガラス面にせず、入力欄の下で 44pt のボタンとして描く。値・リセット・取得不可の説明は OS 標準ポップオーバーへまとめる（仕様書 AC-7-1〜8）。
