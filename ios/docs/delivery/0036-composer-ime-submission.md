# 変換中の本文を含めた送信

## 原因と修正

日本語変換中の本文は UITextView だけが保持し、確定後の本文通知も次の MainActor 処理へ遅延する。一方、送信は確定済み Binding を先に読むため、未確定部分が欠けた本文を送信し、後から届いた全文が入力欄に残っていた。

- 共通の `DSInputBar` で、表示中の全文を使って送信可否を判定する。
- 送信操作で `unmarkText` を呼び、本文・カーソルを同期してから既存の送信処理を呼ぶ。
- 送信前の遅延通知を無効化する。本文が同じ描画周期で「空→確定済み全文→空」へ戻る場合も、送信確定の世代を渡してネイティブ表示へクリアを届ける。
- 最新devのplaceholder修正（`9f823c49`）と併用し、変換表示の独立した通知を維持する。送信時にはその通知も無効化し、表示状態を確定する。
- 新規チャット・既存チャット・自由回答が同じ入力欄を使う。APIと送信結果に応じた編集保護は既存処理を使う。

## 検証

最新devと組み合わせた作業ツリーで実施した。

| 検査 | 結果 |
|---|---|
| iOSホスト付き検査 | 31テスト・3スイート成功。未確定文字のみ、確定済み本文との混在、画像マーカー、遅延通知、送信後の消去、失敗時の保持、フォーカス維持、placeholder、スキル候補を含む |
| PhloxKit | XCTest 402件・Swift Testing 676件、計1,078件成功 |
| iOSコンパイル・リンク・静的解析 | `xcodebuild test` と `xcodebuild analyze` 成功 |
| raw-value lint・差分の空白検査 | 成功 |

新規検査は `ios/PhloxMobileSnapshotTests/ComposerIMESubmissionTests.swift` に登録した。UIKitの `setMarkedText` で入力を作り、実際の送信ボタンをAX操作する。フォーカスありの検査では、未確定範囲の存在を確認して同じMainActor処理中に送信し、シミュレーターが待機中に入力を取り消す条件と区別する。AX初期化の非公開APIはテストだけで使い、利用できなければ検査は失敗する。XCUITestやmacOS入力ソースの追加は行っていない。

画面遷移警告は検証用ウィンドウの扱いを直して0件になった。シミュレーターの触覚素材 `hapticpatternlibrary.plist` 欠落ログは継続している。送信中・画像添付時とスキル候補の画面を描画したが、全盤面や物理端末の日本語キーボード操作は未検証。見本のHTMLには描画用 `support.js` が同梱されておらず、見本とのブラウザー比較も未確認。

## 共通マージ検査と明示承認された例外

最初の共通品質検査ではMacのSessionFeatureで、外側クリックによるポップオーバー終了の2条件と、候補の説明文アニメーションの1条件が失敗した。DashboardFeatureの既存XCTestには6件中1件のスキップもあり、その理由は成功要約ログでは確定できなかった。

ユーザーの「無視してdevにマージして」により、今回の実行だけ次の `SWIFT_TEST_SKIP` を指定する。

- `clickingOutsideClosesNativePopover`
- `popupAnimatesOnlyTheSelectedDescription`

最新devでは外側クリックの合成テストは別作業で既に削除されており、本作業ではその削除を変更していない。現在の検査で実際に除外されるのは説明文アニメーションの1条件。除外した条件を検証成功とは扱わず、リポジトリの品質設定・期待値は変更しない。文書保守と秘密情報検査は共通ツールの通常手順を使う。

除外後の品質検査は一度成功したが、DashboardFeatureの古い固定ファイルが `swift-argument-parser` 1.8.1から1.8.2へ自動更新され、候補の整合性検査で停止した。最新devにはSessionFeature・AppBootstrapと整合する1.8.2の固定ファイルが入り、固定版だけの依存解決も成功している。依存の要求範囲は変更していない。依存解決の一時確認で使った `--skip-update` には廃止予定警告が出たが、永続設定には追加していない。

前提不足のまま試した対話操作を要する全体UI検査は失敗・中断しており、上記31テストの成功とは区別する。専用ビルド・画像・生ログは保持要件がないため、後片付けで処分し、本書に結果と既知の例外を残す。
