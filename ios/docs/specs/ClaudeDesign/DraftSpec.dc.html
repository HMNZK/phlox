画面の作り
  • 入口は 2 つ。一覧のプロジェクトの「＋」から開くと、そのプロジェクトを選んだ状態で始まる（盤面 DraftFromProject: SimpleBudget の「＋」）。下部の「新規チャット」から開くと、前回使ったプロジェクトが選ばれている（盤面 Draft: Phlox）。どちらもプロジェクトのチップで変えられる
  • プロジェクトのチップを押すと、メニューに一覧に出ているプロジェクト（セッションが 1 つ以上あるもの）を並べ、選択中に ✓、前回使ったものに「前回使った」と添える（DraftProject・ダーク・SE）
  • 開いた時点で入力欄にフォーカスが入り、キーボードが上がった状態で始める。ナビは左上のホームのボタン（家の形・押すと一覧へ）だけ。セッション画面と同じで、画面の左端からの右スワイプでも一覧へ戻れる（2 回目の修正 6/6 でそろえた）
  • 中央に見出しを 1 つ。キーボードと入力欄と提案チップを除いた残りの中央に置く。書体は DotGothic16（Mac と同じ。ロゴは付けない）。開くたびに下の 10 種から 1 つ
  • 入力欄の上に提案チップを 5 つ横に並べ、はみ出す分は横スクロール（右端を薄くぼかす）。押すと定型文が入力欄に追記される（送信はしない）
  • プロジェクトが未選択のまま送ると、入力欄の上に赤い文字で「プロジェクトを選んでください」（送らない）
  • 送ると「作成 → 準備待ち → 送信」まで進み、そのセッション画面へ移る。進み具合は会話の中のカードに文字で出す（記号なし、待つ段だけスピナー）。失敗したら本文を入力欄に戻し、入力欄の上に赤い文字で理由

注記: iPhone から作るセッションの作業フォルダ
  • iPhone から作るセッションは、プロジェクトで別の作業フォルダ（worktree）を使う設定になっていても、常にプロジェクトの既存のフォルダで始まる
  • iPhone からは、ブランチ・作業フォルダ・履歴からの再開を指定できない。選ぶ画面・項目は足さない
入力欄（新規チャットとセッション画面で共通）
  • 1 段目: 本文。プレースホルダ「やりたいことを入力」。複数行で伸びる（5 行まで、その先は欄の中でスクロール）。添付画像のサムネイルは 1 段目の上に並べる（「画像 n/4」）。添付の上限とエラー文言は前回の決まりのまま
  • 2 段目: 左から「＋」（画像の添付）、モデルのチップ（{ロゴ} {モデルの表示名} ⌄）、思考の強さのチップ（メーターの印＋段階）、権限のチップ（盾の印＋権限の名前）。右寄せで、プロジェクトのチップ（新規チャットのときだけ。フォルダの印＋名前 ⌄）と、円形の送信ボタン「↑」（実行中は停止「■」）
  • 幅が足りないときは Mac と同じ順で省く: ① 思考の強さと権限を「…」1 つのメニューにまとめる ② プロジェクトのチップを印だけにする ③ それでも入らなければ 2 段目を折り返す。モデル名と送信ボタンは省かない。幅は文字の量から計算して決める（428pt の新規チャットは「Manual」なら ① の前、「Accept Edits」や長いプロジェクト名で ①。375pt と Dynamic Type 最大は ① 以降。「…」を開いた状態は DraftMoreSE・DraftMoreDT）。強い権限（Bypass Permissions・Full Access）を選んでいるときは、権限を「…」に入れず赤いチップのまま見せ、「…」には思考の強さだけを入れる（DraftPermDanger・DraftPermDangerCodex・ReplyPermDanger）
  • 入力欄の上の 1 行は、赤い文字の知らせに使う（プロジェクト未選択・権限や思考の強さを変えられなかった・添付エラー・作成の失敗）。記号は付けない
  • 送信と停止の出し分け・送信中も入力欄を消さない・完了やエラーの後も入力できる、は前の決まりのまま（ReplySpec の表）
  • 入力欄の下（画面の最下端の手前）に使用量の 1 行: Claude Code → Codex → Cursor の、枠ごとの残りのリング。キーボード表示中も出す。押すと吹き出しで枠・残り・リセット（2 回目の修正 5/6。決まりは SetUseSpec、盤面は「使用量 · …」）
思考の強さ
  • メーターの印＋「低／中／高／非常に高／最大」。押すと段階のメニュー（選択中にチェック、既定に「既定」）
  • Claude Code は 5 段階。Haiku は思考の強さが無いので、チップを出さない
  • Codex と Cursor は、モデルごとに Mac から届く段階だけを出す（届かないモデルはチップを出さない）
  • モデルを変えると、そのモデルの既定の強さに戻る（Claude は「高」）
  • 新規チャットでもセッション画面でも変えられる。実行中に変えたら次の指示から効く
権限
  • 盾の印＋権限の名前。押すと権限のメニュー。選択肢はエージェントごとに違う:
    Claude Code: Manual・Accept Edits・Auto・Bypass Permissions・Don't Ask・Plan
    Codex: Read Only・Default・Full Access・Plan
    Cursor: 既定・Ask・Plan
  • 確認なしで全部を許す権限（Bypass Permissions・Full Access）は、メニューで赤い文字＋「確認あり」。選ぶと確認のダイアログ（Dialogs P1・P2）。選んだ後はチップの文字も赤で、幅が足りなくても「…」に隠さない。Codex・Cursor の権限のメニューは DraftPermCodex・DraftPermCursor
  • 実行中に変えたら次の指示から効く。変えられなかったら入力欄の上に「権限を変更できませんでした」（元の権限のまま）
  • 既定は、Claude Code「Manual」・Codex「Default」・Cursor「既定」とした（分岐 Mac の既定に合わせる）
モデルの選択
  • チップは「{エージェントのロゴ} {モデルの表示名} ⌄」。エージェント名の文字は出さない。VoiceOver は「モデル、Codex: gpt-6.1-sol」と読む
  • 新規チャット: 絞り込み欄つきのシートに、3 エージェントの全モデルを 1 つの一覧で。Claude Code → Codex → Cursor の順に、ロゴと名前の見出しで区切る。選択中にチェック、既定に「既定」。取れないエージェントは「取得できません」の行（選べない）
  • モデルを選ぶと、エージェントもそのモデルのものに切り替わる（思考の強さはそのモデルの既定、権限はそのエージェントの既定に）
  • セッション画面: そのセッションのエージェントのモデルだけ
  • モデル名は Mac から届く表示名のまま（盤面の名前は例: Opus (1M context)・Sonnet 5・Haiku 5.5・gpt-6.1-sol ほか）
