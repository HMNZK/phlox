一覧の構成（上から）
  1. 対応待ち（前の「あなたの番」）: 承認待ち・質問ありのセッション。見出し＋件数。カードに中立の細い縁。開閉はしない
  2. プロジェクトごとの欄: 見出しの行＝開閉の印・プロジェクト名、右端に「＋」（そのプロジェクトで新規チャット）。iPhone にはマウスを乗せる操作が無いので「＋」は常に出し、44pt のタップ領域を取る。見出しの残りの部分を押すと開閉
  3. 閉じたプロジェクト: 見出しの右に「エラー 1」「実行中 1」「未読 2」のような文字で内訳。状態の語は行と同じ色、未読は副文字色
  4. その他（プロジェクト未割当）: 最後の欄。開閉できる。「＋」は付けない（プロジェクトを決めずに始めるときは下端の「新規チャット」）
  5. 一覧に出るプロジェクトは、セッションが 1 つ以上あるものだけ（Mac から届く情報の都合）。空のプロジェクトの欄は作らない
セッションの行
  • セッション名と、右端の状態の文字だけ。エージェントのアイコン・ロゴ・状態の記号は出さない。高さ 48pt（Dynamic Type 最大で 64pt 以上、名前は折り返す）
  • 状態の文字: 待機は出さない／承認待ち・質問あり・エラーは注意の色、無応答は紫（status.stalled。いずれも semibold）／実行中は副文字色／完了・起動中・終了などは 3 段目の文字色
  • 未読は名前を主文字色・semibold、既読は副文字色・標準の太さ。未読の丸は使わない
  • 実行中は名前に光の帯がゆっくり流れる（3.2 秒で 1 回）。「視差効果を減らす」では止め、名前をふつうの色で出す。盤面では帯が名前の左寄りにある瞬間を描いた
  • 子セッションは 1 段（22pt）字下げし、左に案内線。子を持つ行は左端の開閉の印で開閉し、閉じると名前の後ろに「+3」（孫まで数える）
  • VoiceOver:「refactor: ControlServer proxy、実行中、未読」／子は「…、1 段下の子セッション」／開閉の印は「… の子セッション 3 件、折りたたみ中」
下部のナビゲーション（Liquid Glass 採用案）
  • タブバーは「セッション」「設定」の 2 つ（左 20pt・高さ 62・ガラスのカプセル）。右に 10pt 離して、丸いガラスの「新規チャット」ボタン（62pt、iOS 26 のタブから離した丸いボタンの形）。設定タブを見ているときも同じ位置にある
  • 「新規チャット」は新規チャットを開く。プロジェクトは入力欄のプロジェクトのチップで選び、初期値は前回使ったプロジェクト（DraftSpec の決定）。そのプロジェクトで始めるときは、その欄の見出しの「＋」
  • 対応待ちバーはタブバーの上（左右 16pt）。一覧をスクロールすると、タブバーは左の丸に縮み、対応待ちバーは丸と「新規チャット」の間に入る
  • iOS 18: タブバーは OS 標準（端から端・素材・上の線）。「新規チャット」は一覧の大見出しの右（44pt）に置く
  • 移動 使用量: 移動元 一覧の下端の使用量バー（前回の改訂で置いた）→ 移動先 新規チャットとセッション画面の、入力欄の下の 1 行のリング（押すと枠・残り・リセットの吹き出し。2 回目の修正 5/6、盤面「使用量 · …」）。一覧の引っ張って更新で使用量も取り直す（表示は消さない）。「使用量」タブは廃止のまま、使用量だけを見せる画面・タブ・設定の区画は作らない（設定の「使用量 › 残りの表し方」も外した）

決めてほしい候補・分岐
  • 決定 状態の色: 承認待ち・質問あり・エラーはそれぞれの注意の色（琥珀・青・赤）、無応答は Mac と同じ紫（status.stalled: #5B3FA8／ダーク #C9B6FF）。行の文字・閉じたプロジェクトの内訳・セッション画面の小見出しと面・アプリ外の表示で同じ色。承認待ちは Claude Code と Codex のセッションだけ（Cursor には承認が無い）
  • 分岐 対応待ちのセッションを、プロジェクトの欄にも重ねて出すか。モックは重ねていない（前の一覧と同じ）
  • 候補 エラー・無応答のセッションも対応待ちに入れるか。モックは承認待ち・質問ありだけ（現行どおり）
  • 分岐 子セッションの開閉の既定（開いているか閉じているか）と、開閉の状態を覚えるか。モックは親ごとに描き分けた
  • 候補 行の長押しメニュー・スワイプは足していない。足すなら詳細の「…」と同じ名前変更・削除の入口を増やす案になる
未配置の機能: なし。移した機能: 使用量（一覧の下端 → 入力欄の下の 1 行のリング、5/6）／行のエージェントのロゴと名前（行 → 詳細の小見出し）／行の補足のワークスペース名（行 → プロジェクトの欄の見出し）／相対時刻（行から外した。指示による）。追加した機能: なし（「新規チャット」の丸ボタンと見出しの「＋」は、既存の新規作成の入口の置き場所を変えたもの）
