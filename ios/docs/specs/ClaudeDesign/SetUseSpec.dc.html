C を採用する。前回は B（一覧の下端のバー）を採用していたが、次の理由で改める。
① 残りを見たいのは、指示を書いて送る瞬間。エージェントやモデルを選び、どれだけ頼むかを決めるのは入力欄の前にいるとき。B では一覧に戻らないと見えず、詳細画面（いちばん長くいる画面）では見えなかった。入力欄の真下なら、送る前に必ず目に入る
② リングは「残り」を幅に頼らずに示せる。横棒は長さを比べるのに横幅が要り、iPhone の幅ではリセットや枠の名前を省くしかなかった。リングは 18pt の正方形で、3 エージェント × 2 枠が 1 行に収まる（SE でも 1 行。Dynamic Type 最大は 2 行）。省いた情報は、押して出す吹き出しにまとめた
③ 入力欄の主役を奪わない。リングは副文字色で、文字は Claude Code の「5h」「7d」だけ。色が付くのは残り 20% 未満の枠（注意の色）だけで、記号は付けない。入力欄・承認のカードより常に一段弱い
④ ADR 0007「面にいつでも行ける」は形を変えて守る。使用量は入力欄のある画面に常にあるので、行く操作そのものが要らない。タブは「セッション／設定」の 2 つのまま
代わりに受け入れること: 入力欄の下に 44pt の行が増え、会話の見える範囲がその分だけ減る（キーボード表示中も出すので、SE では会話がさらに狭くなる）。一覧の画面には使用量が出ない（引っ張って更新で取り直しはする）。リセットは吹き出しを開かないと見えない（VoiceOver も同じで、行をダブルタップして吹き出しで読む）。
設定の並べ方（探しやすくする）
  • 上から「困ったときに開く順」: 接続 → 通知 → セキュリティ → 外観 → このアプリについて（使用量の区画は 2/6 で外した）。接続が切れたときに設定を開く人が最初に見る場所に、接続の状態を置く
  • 接続は「状態の行」を先頭に: 「Mac と接続中」（緑の文字）／「Mac に届きません」（赤い文字）。記号は付けない（アプリ内は文字だけ。記号はロック画面・ウィジェット・Live Activity・Dynamic Island だけ）＋接続先（等幅）＋最終取得。その下に「QR で再接続」「疎通テスト」
  • 設定に使用量の区画は置かない（2/6 で「残りの表し方」を外し、5/6 でリングだけの表し方にしたので、選ぶものが無い）
  • 行の頭に同じ形のアイコンをそろえ、見出しを読まなくても目で探せるようにする。色は中立の淡い灰色 1 色（状態の色とぶつけない）
  • ロックの文言は端末に合わせて「Face ID でロック」または「Touch ID でロック」の片方だけを出す（現行は両方を併記）
  • 外観は 3 つの見本つきの選択。押した瞬間に画面全体が切り替わる（ADR 0004）
  • About は「このアプリについて」に。バージョンは等幅（技術的な値）
  • タブバーは Liquid Glass の浮いたカプセル（左右 20pt）、対応待ちバーはその上のガラスのカプセル（左右 16pt）。対応待ちバーの状態も文字だけ（「承認待ち」を琥珀の文字に）。タブは「セッション」「設定」の 2 つ。設定を開いていても、対応待ちバーは下端に出る（使用量は入力欄のある画面だけ）
使用量の行の決まり（盤面「使用量 · …」の 22 枚）
  • 置き場所: 新規チャットとセッション画面の、入力欄の下（画面の最下端の手前）に 1 行。キーボード表示中も、入力欄とキーボードの間に出す。一覧・設定・サブエージェント詳細（入力欄が無い画面）には出さない
  • 並び: Claude Code → Codex → Cursor。どの画面でも全エージェントを出す（そのセッションのエージェントだけに絞らない）
  • Claude Code: ロゴ・「5h」のリング・「7d」のリング（5 時間枠と週次の枠）。リングの右に「5h」「7d」の文字（11pt・副文字色）
  • Codex: ロゴとリング 2 つ（5 時間・週次）。Cursor: ロゴとリング 2 つ（Auto・API）。どちらも文字は出さない
  • リング: 18pt（Dynamic Type 最大は 30pt）、線 2.6pt。弧の長さ＝残り（12 時の位置から時計回り）。弧は副文字色 #56565E（ダーク #C7C7CE）、下地は灰色
  • 残り 20% 未満: 弧を注意の色（#8A5300／ダーク #F4BD68）にし、下地も注意の色の淡い色にする（残り 0% でも灰色の空のリングと見分けられる）。「5h」「7d」の文字も注意の色。記号は付けない
  • 取得できないエージェント: ロゴはそのまま、リングは灰色の空のリング。期限が切れた枠は Mac から届かないので、その枠だけ灰色の空のリング（0% と描かない）
  • 古い値（取り直しに失敗）: 前の値のまま、行の右端に「16:12 時点」（副文字色）。取り直しの間は右端に「更新中…」。どちらも表示は消さない
  • 押すと: 行の上に小さな吹き出し（OS 標準のポップオーバー、矢印は Claude のロゴを指す）。見出し「枠／残り／リセット」、エージェントごとに枠の名前・「残り 72%」・リセット。5 時間枠は残り時間「03:12」、週次は日時「10/20 14:00」。Cursor はリセットを出さない。値が届いていない枠は「値なし」、取得できないエージェントは「取得できません」。古い値のときは先頭に「16:12 時点の値です。更新できませんでした。一覧を引っ張ると取り直します」。吹き出しの外を押すと閉じる
  • 行の押せる範囲: 高さ 44pt・入力欄と同じ幅（Dynamic Type 最大で 2 行になったら 88pt）
  • 取り直し: 一覧の「引っ張って更新」で使用量も取り直す。取り直しの間も表示を消さない。候補 一覧を取得するとき（起動・復帰）にも一緒に取る
  • VoiceOver: 行全体を 1 つのボタンとして読む。「使用量。Claude 5時間 残り 72%、週次 残り 40%。Codex 5時間 残り 99%、週次 残り 85%。Cursor Auto 残り 80%、API 残り 95%。」残り 20% 未満は「残り 12%、残りわずか」、届かない枠は「週次 値なし」、取得できないエージェントは「Cursor 取得できません」、古い値は先頭に「16時12分時点の値。更新できませんでした。」。ダブルタップで吹き出しを開く
