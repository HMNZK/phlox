# ADR 0122: live agent model catalog

Claude、Cursor、Codex の spawn 前モデル一覧は、起動時に CLI / app-server から取得して同期スナップショットへ公開する。取得失敗時は内蔵既定値を返し、その状態を観測可能にする。これにより Codex の空カタログという ADR 0085 / 0087 の判断を supersede する。

`/model` が提示する `default`、`opusplan`、`[1m]` 付き alias は除外しない。CLI 自身が選択肢として提示しており、未知値を弾くと新モデルを選べても spawn できない不整合を生むためである。表示名が未取得の ID は ID 自体を表示する。

## 2026-09-08追記：既存の対話型ピッカー仕様への変更を記録

上記の「提示aliasを除外しない」と「表示名未取得時はID」の部分は、2026-09-05のコミット`d37a01d7efa4759ec2cdbfb230ea780a370437f5`で変更済み。[現行構造](../architecture/agent-model-catalog.md)と実コードを照合し、このADRへの反映漏れを追記する。新たな製品仕様変更ではない。

Claudeの非対話応答には対話型にない内部aliasも含まれるため、対話型で観測した5件と取得済みaliasの共通部分を表示する。表示名照会に失敗した項目は当該項目の内蔵表示名を保持する。live取得と失敗状態の観測という原決定は維持する。観測日は上記コミットの記録であり、今回CLIの対話型画面を再実測したという意味ではない。固定スナップショットの陳腐化リスクは現行構造の「フォールバックと観測」に残る。
