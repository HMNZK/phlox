# 0184: アクセント色を藍色 #3B469B にし、使う場所を絞り、ハーネスごとの色を廃止する

## 決定

- UI のアクセント色を、コーラル（#D97757 / #E08865、主ボタンの面 #B4552F）から **#3B469B** に替える。全テーマ共有の UI アクセントという形（ADR 0042）は変えない。外部テーマは背景の明るさでライトかダークの値を使う。
- ダークでは、主ボタンの面だけ #3B469B（白文字）にし、文字・フォーカス枠・印は同じ色相を明るくした **#959CD0** にする。
- アクセントを使うのは、主要な操作・選択・フォーカス・リンクに限る。それ以外の装飾は中立の色にする。
- フォーカス枠は不透明にする。選択の面と文字選択の色は、直書きをやめてアクセントのトークンから取る。
- ハーネスごとの色（Claude Code #E0AF68・Codex #7C8CFF・Cursor #B8B8B8）を廃止する。
- 注意の色・差分の色・アプリアイコンは変えない。

## 理由

アクセントがコーラル系だけで約 157 か所に広がり、「オレンジが多い」状態だった。アクセントは主要な操作に絞るのが原則で（60-30-10、macOS HIG）、絞らないと本当に押すべき所が目立たない。色はユーザーが #3B469B を選んだ。

#3B469B はダークの背景（#1E1E20）との比が 2.01 で、文字（4.5:1）にもフォーカス枠（3:1）にも足りない。白文字を載せる面としては 8.28 あるので、面はそのまま使い、文字と枠だけ明るくした（#959CD0 は #1E1E20 で 6.30、#2A2A2D で 5.41）。今のフォーカス枠は不透明度 25〜30% で 3:1 に届かないので、不透明にする（WCAG 2.2 AA）。

ハーネスごとの色は、略号の背景とロゴの無いカスタムハーネスの代わりの印にしか使われておらず（カスタムは ADR 0185 で廃止）、略号と図形の廃止（ADR 0183 の要件 D14）で使い道が無くなる。Codex のロゴは識別色ではなく文字色で描いている。

## 結果

- アプリ全体の見た目が変わる（主ボタン・選択・フォーカス・リンク）。外部テーマ由来のテーマでも同じアクセントになる。
- iOS のテストが `AgentDescriptor` を作っている所（`colorRGB` 引数）を直す。iOS アプリの動きは変わらない。
- コントラストは `DesignPaletteTests` で検査する。既定 2 テーマの 3 段目の文字色が 4.5:1 未満なのは 2026-09-24 のユーザー決定のまま。

詳細は [要件](../specs/unified-new-chat-start.md) §6.8 と [設計](../specs/unified-new-chat-start-design.md) §9.1。
