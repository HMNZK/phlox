# 0185: 画面からターミナルのセッションを始める経路と、カスタムエージェントを廃止する

## 決定

- 画面（メニューバー・プロジェクト行のメニュー・新規チャット画面）から始められるのはチャットのセッションだけにする。ターミナルでエージェントを動かすセッションを始めるメニューは作らない。ターミナルでエージェントを使いたいときは、ユーザーが普通のターミナルに自分でコマンドを打つ（Phlox のセッションとしては登録されない）。
- 保存済みのターミナルのセッションの復元と、Control API・CLI の `backend: pty`（組込ハーネスのみ）は残す。他のエージェントからの委譲で使うため。
- カスタムエージェント（`~/.config/phlox/agents.json` で任意の CLI を足す機能）を廃止する。`AgentRef` は組込だけにする。保存済みのカスタムのセッションは読み込みで捨て、件数を 1 回知らせる。
- ADR 0183 の「ターミナルはメニュー『新規ターミナルセッション ▸』から始める」を置き換える。

## 理由

ユーザーは、画面からの始め方をチャット 1 つにしたい。ターミナルの起動経路を残すと、新規チャット画面と別に入口と選択肢が残る。

カスタムエージェントはチャットに対応せず、ターミナルのセッションとしてしか動かない。画面からのターミナル起動を無くすと使う道がほぼ無くなる。利用者の環境に定義ファイルは無く（2026-10-11 確認）、残すと `AgentRef` の分岐・仮の descriptor・バイナリ表・設定画面の行など約 30 ファイルの複雑さが残る。

## 結果

- カスタムエージェントは使えなくなる。保存済みのカスタムのセッションは消える（元の `sessions.json` は `sessions.json.corrupt-<日時>` に残る）。
- Control API に未知の `kind` を送ると 400 になる。
- 課金なしで動かす E2E・UI テストは今カスタム（`fake-agent`）を使っているので、組込ハーネスの実行ファイルの場所を差し替える形に移す。
- `specs/custom-agents-json.md` は置き換え済みになる。

詳細は [要件](../specs/unified-new-chat-start.md) D1・D22・§8.6 と [設計](../specs/unified-new-chat-start-design.md) §8・§8.1。
