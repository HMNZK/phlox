# 0186: 使用量をヘッダーから画面下部のバーへ移し、対応待ちの一覧を廃止する

> **追記（2026-10-13）**: インスペクタの使用量タブを廃止した（ADR 0192）。バーは押しても何も開かない。

## 決定

- ヘッダーから「対応待ち」ボタンと使用量のチップを消す。対応待ちの一覧（ポップオーバーと ⌥⌘J）は廃止する。⌘J（次の対応待ちへ）・サイドバーの対応待ちの欄・Dock のバッジは残す。
- 使用量はウィンドウの一番下の全幅のバーに出す。全ハーネスの全枠の残りを、小さめの文字で横に並べる。インスペクタを開いていても出す。設定 `phlox.usage.showInHeader` はキーを変えずに「画面下部に使用量を表示」の意味にする。
- 単体／グリッドの切替はヘッダーの右寄せにする。
- ADR 0112 のうち「インスペクタ表示中はヘッダーに出さない」を置き換える。設定で消せること、「未取得の CLI も表示」を両方に当てることはそのまま。

## 理由

ユーザーは、ヘッダーを軽くし、使用量を常に全部見たい。今のチップは全枠のうち最も減っている 1 つしか出さず、略号（Cl・Cx・Cu）も廃止する（ADR 0183 の要件 D14）。

対応待ちは、略号と図形の廃止に合わせてサイドバーのセッション行に状態の文字を出すので、一覧で見る必要が薄い。一覧から許可・拒否・回答・中断ができる機能は失うが、ユーザーは一覧ごとの廃止を選んだ（2026-10-11）。

## 結果

- 一覧から直接許可・拒否・回答・中断はできなくなる。そのセッションを開いて行う。
- 縦の表示領域がバーの高さ分減る。
- 詳細は [要件](../specs/unified-new-chat-start.md) §6.9。
