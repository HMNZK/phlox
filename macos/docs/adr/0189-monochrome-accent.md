# 0189: アクセントの色をやめ、白黒にする

ADR 0184 のアクセント色 #3B469B / #959CD0 を置き換える。アクセントを使う場所を絞る方針と、ハーネスごとの色の廃止は 0184 のまま。

## 決定

- アクセントは、各テーマの主文字色と同じ白黒にする（ダークでは白、ライトでは黒）。外部テーマも同じく、そのテーマの主文字色を使う。
- 主ボタン・送信ボタンの面はアクセント（白または黒）にし、その上の文字・記号は背景色で描く（新しいトークン `accentOnFill`）。
- 選択中の行の面は無彩色の面にする。フォーカス枠は今どおり不透明。
- 注意の色・差分の色・アプリアイコンは変えない。

## 理由

ユーザーが藍色のアクセントをやめることを選んだ（2026-10-13）。白黒は背景との比が最も高く、フォーカス枠（3:1）と文字（4.5:1）の基準をどのテーマでも満たす。色を足さないので、注意の色（承認待ち・エラーなど）がより目立つ。

## 結果

- 主ボタンの上の文字を白に固定していた箇所は、`accentOnFill` に替える（ダークで白い面に白い文字になるのを防ぐ）。
- 送信ボタンのホバー・押下の色の直書き（藍）をやめる。
- コントラストは `DesignPaletteTests` で検査する。
- 詳細は [要件](../specs/unified-new-chat-start.md) D29・§6.8。
