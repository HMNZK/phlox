# 0190: 選択肢のポップアップの見た目を 1 つの部品にまとめる

## 決定

- 選択肢の一覧を出すポップアップ（新規チャットのチップ・会話の入力欄のモデル／effort／権限／ブランチ・`/` と `@` の補完・タブの「＋」・ほか n・履歴の巻き戻し・入力履歴・グリッドのセッション選択）は、行の強調と外枠を DesignSystem の共通部品で描く。
  - 行の強調は `dsPopupRowHighlight(_:)`。ホバーとキーボードの選択は同じ見た目で、面は `selectionFill`（主文字色の淡い面）、角は `DSRadius.row`。文字の色は強調しても変えない。
  - 自前で浮かせる外枠は `dsPopupSurface()`。面は `popoverBackground`、縁は 0.5pt の `popoverEdge`、角は `DSRadius.attention`、影は `DSShadow.popover`。システムの `.popover` に載せるもの（タブの「＋」・グリッドのセッション選択）は、システムの枠に任せて面だけ塗る。ただし `SelectablePopover` は新規チャットのチップで見た目の基準にしたものなので、`.popover` の中でも同じ外枠を描く。
- 白の塗りつぶしに文字を反転させる強調（`accentFill`・`accentOnFill`）はポップアップの行に使わない。

## 理由

行の強調の色が 4 種類（`fillSubtle`・`fillSelected`・`selectionFill`・`accentFill`）に分かれ、タブの「＋」と新規チャットのチップで明るさが違って見えた（2026-10-13 ユーザー指摘）。外枠も部品ごとに手書きで、角の丸みが 9・10・12pt とずれていた。アクセントを白黒にした（ADR 0189）ので、白の塗りつぶしの強調は特に目立っていた。

## 結果

- 強調の色と外枠は共通部品を直せば全部に効く。新しいポップアップも同じ部品を使う。
- 入力履歴の外枠は Liquid Glass 風の面をやめ、共通の外枠にそろえる。
- システムの `Menu`・右クリックメニューは強調の色を変えられないので対象外。
- 履歴から再開の行は、枠付きのカード（`HistoryStartRow`）で選択肢の一覧とは別の部品なので対象外。
- 詳細は [デザインシステム](../architecture/design-system.md) §5.2。
