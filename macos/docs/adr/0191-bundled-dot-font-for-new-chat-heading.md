# 0191: 新規チャットの見出しにドット書体 ベストテンDOT を同梱する

## 決定

- 新規チャットの挨拶の見出し（`DSFont.newChatHeading`）は、ドット書体 ベストテンDOT（フロップデザイン）の 30pt で描く。
- 書体ファイル `BestTen-DOT.otf` とライセンス文 `BestTen-LICENSE.txt` は DashboardFeature パッケージの資源（`NewChat/Fonts`）に置く。DesignSystem は iOS アプリとも共有しているので、そこに置くと使わない iOS アプリにまで 1.2MB の書体が入る。
- 書体の登録は `NewChatHeadingFont.font` を初めて参照したときにプロセス内へ 1 回だけ行う。画面外の描画テストでも同じ経路で登録される。
- 大きさは 10 ドットの格子の 3 倍の 30pt にする。32pt だと 1 ドットが 3.2pt になり、ドットの大きさがそろわない。

## 理由

見出しをドット書体にしたい（2026-10-13 ユーザー指示）。アプリにはドット書体が無かった。見出しは日本語なので、和文を持つ書体に限られる。

最初は DotGothic16（16 ドット）を入れたが、ドットが細かく普通の書体と見分けにくかった。DotGothic16・美咲ゴシック（8 ドット）・ベストテンCRT・ベストテンDOT を同じ文字列で描き比べ、ドットらしさと読みやすさの釣り合いからユーザーがベストテンDOT を選んだ。

- 美咲ゴシックはドットが最も粗いが、漢字が詰まって読みにくい。
- ベストテンCRT は角を丸めた加工で、ドットらしさが薄れる。
- 魔導太丸ゴシックは、著作権表記が SEGA/D4Enterprises で、アプリに入れて配ってよいかが確認できないので外した。

ベストテンDOT は M+ FONT LICENSE に準じ、プログラムへの埋め込み・再配布・商用利用を許している。かな・英字はフロップデザインのオリジナル、漢字は PixelMplus10（M+ BITMAP FONTS の派生）を使う。

どのドット書体でも、「日」のようなまっすぐな線は 1 粒ずつのドットには見えない。粒に見せるには書体ではなく描き方を変える必要があり、今回はそこまでしない。

## 結果

- macOS アプリが約 1.2MB 大きくなる。
- ライセンスは `THIRD_PARTY_NOTICES.md` に載せ、`BestTen-LICENSE.txt` を書体と一緒に同梱する。
- 登録に失敗すると `Font.custom` はシステムの書体に黙って戻る。登録は書体の名前が引けることをテストで確かめる。
