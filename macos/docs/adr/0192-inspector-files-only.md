# 0192: インスペクタの「使用量」と「セッション」のタブを廃止し、ファイルだけにする

## 決定

- 右サイドバー（インスペクタ）の「使用量」と「セッション」のタブを、その機能ごと消す。インスペクタはファイルツリーだけを出し、上のタブの切り替えも無くす（`InspectorTab` と `AppRouter.inspectorTab` も消す）。
- 消える機能:
  - 使用量: CLI ごとのカード（全枠の残りとリセットまでの時間）・取得失敗の理由と時刻・手動の「更新」ボタン・Cursor のインストールへの誘導・初回取得中の骨組み。
  - セッション: 選んだセッションの経過時間・総コスト（ADR 0038 の累計）・Git ブランチ・プロジェクト名（`SessionInfoPanel`）。
- 使用量は画面下部のバー（ADR 0186）だけで見る。バーは押しても何も開かない（ボタンでなくなる）。
- 使用量の取得そのもの（`UsageMonitor` の定期更新・設定「自動で更新する」「Claude の使用量を取得する」・モバイルへの同期）は残す。インスペクタを開いたときの取り直しは、開く理由が無くなったので消す。

## 理由

ユーザーが 2 つのタブと機能をすべて消すよう指示した（2026-10-13）。使用量は下部のバーで常に見えるので、同じ情報の詳細を別の場所に持つ必要が薄い。

## 結果

- リセットまでの時間は、下部のバーの幅が十分なとき（1100pt 以上）だけ見える。取得失敗の理由・最終取得時刻・手動更新は見られなくなる。
- 手動の更新が無くなるので、設定「自動で更新する」がオフでも起動時に 1 回は取得する（オフのままだと使用量が一度も出なくなるため）。
- セッションの総コストはアプリのどこにも出なくなる。会話の各ターンの下のコスト表示（ADR 0038 の `.turnCost`）は残る。セッションの総コストの累計（`sessionTotalCostUSD`・保存形式の `SessionTotalCost.totalUSD`）も消す（2026-10-13 ユーザー指示）。各ターンのコストに要るのは Claude が最後に送った累計（`lastReportedUSD`）だけで、こちらは保存も含めて残す。以前に保存したファイルの `totalUSD` は読み飛ばす。
- ADR 0038 の「セッション累計は右サイドバーに表示」、ADR 0186 の「バーを押すとインスペクタの使用量を開く」は、この決定で置き換える。
