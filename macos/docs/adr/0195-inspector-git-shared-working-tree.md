# 0195: インスペクタに共有作業ツリーの Git タブを戻す

## 決定

- 要件 GT-1〜GT-9 に従い、右サイドバーに「ファイル / Git」の切り替えを置く。ADR 0192 の「ファイルだけ・切り替え無し」を置き換える。使用量・セッションの廃止は維持する。
- 一覧と取得状態は既存の `EditorPanelCoordinator.viewModel` を「変更」タブと共有する。Git 側の選択は独立させ、変更タブの編集中の下書きを上書きしない。差分の読み取りは同じ `WorkingTreeService` を通す。
- 上下分割の Git プレビューは60行、300pt以上で行番号を出す。書き込み操作は既存の変更タブに渡す。重ね表示から渡す場合はカードを閉じる。
- 更新は表示時・対象プロジェクトのターン終了・既存のファイル保存／ツリー操作通知・アプリ前面復帰・手動操作を使う。新しい監視は追加しない。

## 理由

2026-10-14 のユーザー決定により、作業中の差分を右側で小さく確認し、大きな閲覧とコミットは既存の変更タブで行う。一覧を別々に取得すると時点が食い違うため、既存の表示モデルを正本にする。

## 結果

切り替えは終了後も保持する。種類はバイナリも含め A・M・D・R・U。初回の行は新着扱いせず、成功した更新の前後で増えたパスだけを太字にする。Git実行失敗は管理外と区別し、理由と再試行を出す。読み取りには `--no-optional-locks` を使う。
