# 0196: 中央の下部パネルにプロジェクトごとのターミナルを置く

> **追記（2026-10-15）**: 開閉キーを ⌘J に変え、⌃` を端末より先にメニューへ渡す処理を消した（ADR 0200）。

共有表示器の決定は [ADR 0197](0197-bottom-terminal-single-display.md) で置き換える。その他の配置・寿命・操作の決定は継続する。

## 決定

- BP-1〜BP-13 に従い中央列だけに下部パネルを追加する。使用量バーと左右のペインはその外側に残す。ADR 0187 で廃止した共通ターミナルは復活させない。
- `ProjectTerminalStore` が子タブとは別にプロジェクトごとの下部ターミナルを保持する。初回表示でだけ起動し、非表示・プロジェクト切替では終了しない。プロジェクトを閉じたときとアプリ終了時に既存の終了経路で停止する。
- 各ウィンドウの `DashboardView` が専用の `BottomPanelState` を持ち、表示メニューは `FocusedValues` で操作中のウィンドウへ渡す。開閉状態はプロジェクト切替をまたぐ。高さだけを UserDefaults に保存する。
- 高さの計算対象はタブ列より下の中央本文。最小120pt、最大は本文高の70%と上の内容200ptを残す高さの小さい方。中央高が320pt未満では上の内容の確保を優先する。ドラッグ中は境界の予告線だけを更新し、終了時に一度だけ高さを確定する（ADR 0116/0136 のレイアウト更新分離）。
- 開いた時点の入力先を弱参照で保持し、閉じたら同じウィンドウの入力先へ戻す。端末の入力先変更を専用状態だけが観測する。⌃` は端末のキー処理より先に標準メニューへ渡し、Esc はそのまま端末へ渡す。
- 起動・再起動は既存の `UserShellSettings` の解決経路を使う。代替起動の注意は実際の解決結果から見出しに出し、次の再起動まで保持する。終了したシェルは明示的な再起動でのみ復帰する。

当初はウィンドウごとの表示器で端末エンジンを共有した。この方式は ADR 0197 により廃止し、プロジェクトごとに1つのセッション・表示器を保持する。

## 理由

2026-10-14 のユーザー決定により、会話・グリッド・左右分割を保ちながら、選択中プロジェクトの作業を続けられる常駐端末が必要になった。既存の所有者と表示器を再利用し、別の共通シェルや出力バッファは設けない。

## 検証方針

Swift Testing で高さ、保存・開閉、所有者、再起動条件、フォーカス復帰とメニュー優先を検査する。画面外描画で主な状態・日英・明暗とウィンドウ配置を出力し、アプリは起動しない。
