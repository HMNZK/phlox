# 0198: ユーザー用端末の初期設定とヘッダーの操作境界を分ける

## 決定

- ユーザー用シェルだけ OS 標準の端末設定で PTY を開く。エージェントの既定の raw 設定は維持する。
- 子タブと下部パネルの共通工場で専用の `PTYManager` を生成する。
- 表示モード・下部パネル・インスペクタを別の ToolbarItem にする。
- 下部パネルが開いているときはインスペクタと同じ選択の塗り・主文字色・`.isSelected` を使う。

## 理由

2026-10-15 の実操作で bash の入力が表示されず、開閉ボタンが「表示モード」と読まれた。ユーザーの対話端末には echo・icanon と標準の制御文字が必要。共有 PTY の既定を変えるとエージェントへ影響するため、生成時の設定を分ける。ツールバーの操作境界を分けて読み上げのまとまりを限定する。

## 結果

選択属性の方式は [ADR 0199](0199-file-rename-menu-and-accessibility-state.md) に置き換える。その他の決定は維持する。

ADR 0193 のシェル解決、0196・0197 の寿命・単一表示器は維持する。ヘッダー常態の表示を定めた現行 architecture の記述を置き換え、開いたときの見た目は今回のユーザー指示をモックより優先する。新しい設定項目は追加しない。
