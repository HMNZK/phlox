# 0199: 名前変更の開始をメニュー処理から分け、開閉状態をトグルとして公開する

## 決定

- 右クリックの名前変更だけ、メニューのアクションが戻った後のメインキューで `beginRename` を呼ぶ。Return は従来の共通関数を同期で呼ぶ。
- 下部パネルとインスペクタのボタンは、見た目と操作を維持し、アクセシビリティ表現を状態に連動した Toggle にする。
- シェルの選択は Picker の標準ラベルを使い、重複する `.accessibilityLabel` を取り除く。

## 理由

実アプリでは右クリックの名前変更だけで AttributeGraph の循環警告が発生した。同期のアクションが `model.edit` を変更すると、メニューを所有する通常行とその contextMenu が入力行に置き換わる。一方、新規作成は Task 経由で、Return はメニューを経由しない。メニュー処理と行の置換を分ける。

ADR 0198 の `.isSelected` は実アプリで AXSelected に反映されなかった。開閉する二値の操作として公開し、VoiceOver がオン／オフを読めるようにする。シェルの Picker は標準ラベルと追加ラベルが結合され、AXLabel が「シェル, シェル」になることを画面外の同じ Picker 構成で確認した。標準ラベルだけにする。

## 結果

ADR 0198 の選択属性の方式だけを置き換える。既存のトークンによる塗り、独立した ToolbarItem、PTY の設定、入力の選択範囲、ファイルをクリックして開く FO-3、パネルの開閉状態を保存しない決定は維持する。修正後の実アプリ・VoiceOver の音声は未検証。
