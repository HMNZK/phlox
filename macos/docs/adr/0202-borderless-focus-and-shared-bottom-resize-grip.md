# 0202: 一覧と下部端末のフォーカス外枠をなくし、高さの境界を共通部品にする

## 決定

- FX-1〜3・BD-1〜3 に従い、ファイルツリー・Git 一覧・下部端末のフォーカス外枠を描かない。選択行の塗りと下部端末の見出しの強調は維持する。名前変更・新規作成の入力欄の枠は残す。Git の差分には OS 標準のフォーカスリングも出さない。
- BP-9 の外枠の決定を置き換える。BP-7 の高さ制限・保存は維持し、境界の見た目とマウス操作を `ResizeGripView` に統一する。
- `ResizeGripView` の移動方向を左右（既定）と上下から選べるようにする。上下の移動量は下が正。区切り線色の3ptの帯、0.12秒のアニメーション、方向に合うカーソルとドラッグ中の維持、ウィンドウ移動の抑止を共有する。
- 下部境界はドラッグ中に共通部品の位置だけを予告として動かし、終了時に高さを保存する。ダブルクリックで既定の280ptへ戻す（表示領域の制限を適用）。上下キーと VoiceOver の増減操作は維持する。

## 理由

2026-10-15 のユーザー決定。サイドバーの一覧・子タブの端末と入力先の示し方を揃え、下部だけ別の境界操作を持つ状態をなくす。既存の AppKit の掴みしろを再利用すると、カーソルの後始末とウィンドウの固定・復元も同じ経路になる。

## 結果

ADR 0196 の下部パネルについて外枠と境界操作を更新する。Git 内部の一覧と差分の境目は変更しない。Swift Testing で上下の移動量・カーソル・ダブルクリックと下部パネルへの接続を検査し、画面外描画で入力先のある端末とファイルツリーを確認する。
