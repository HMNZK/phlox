# ADR 0205: Git の出どころ別の状態と表示中の操作対象を保持する

## 文脈

ADR 0204 の出どころ別一覧を、パス単位に集約した状態から作ると、ステージ済み削除と同名の未追跡ファイルの片方が消える。折りたたみ後にも選択が残るため、非表示行への操作も発生する。

## 決定

- porcelain v1 -z の各レコードの XY と改名元を保ち、index と作業ツリーを独立して列挙する。互換のパス単位一覧への集約は出どころ別一覧の生成後の用途に限る。
- 行キー操作は表示中の行だけに限定し、折りたたみ時に見出しへ入力先を移す。
- プッシュの状態条件、⌃↩ の行メニュー、コミット欄の ⌘↩、PR メニューを見本へ合わせる。
- 廃止した左右分割の型とテストを削除し、実際の1ペイン表示と共有モデルの選択競合を検査する。

## 理由と結果

既存の Git 実行経路と XY を再利用でき、別の状態取得機構は不要。ADR 0204 のステージ済みだけのコミットと差分の配置は維持する。修正前の再現と修正後の結果は作業報告に記録する。
