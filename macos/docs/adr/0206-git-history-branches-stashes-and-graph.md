# ADR 0206: Git タブに履歴・ブランチ・スタッシュ・グラフを集約する

## 文脈

GW-7〜15 は ADR 0169 の「書き込みは commit・push・PR の3つ」を置き換える。ADR 0204・0205 のステージと表示中の行だけの操作を維持する。

## 決定

- 読み取りは WorkingTreeService の `/usr/bin/git --no-optional-locks`。起点選択と参照列挙を共用する。ローカルの順序は当初 committerdate の降順としたが、[ADR 0208](0208-git-history-review-corrections.md) により HEAD reflog の切り替え先の新しい順へ置き換える。記録のないブランチは最終コミット時刻順で後置する。
- 書き込みは GitWorkflowService に追加する。切り替え・ブランチ作成／改名／削除、追跡付きチェックアウト、fetch、未追跡を含む stash push・apply・pop・drop を扱う。名前は check-ref-format で検査する。暗黙の退避・強制・設定変更は行わない。
- 取得は `fetch --all`。要件は pruning を要求せず、参照の掃除は追加の副作用なので `--prune` を付けない。
- コミットは50件単位。グラフは当初最大200件としたが、ADR 0208 により全参照から最初200件、末尾で次の200件を親子順に追加取得する。親IDをレーンに割り当て、分岐・合流・複数親を描く。札は参照名から分類する。
- 変更・コミット・ブランチ・リモートブランチ・スタッシュ・グラフの順。変更だけ既定で開く。開閉は UserDefaults に保存し、見出しは既存の pinned section header を使う。
- GT-7 と書き込み後は開いた区画を読み直し、閉じた区画を無効にする。閉じた区画は次に開いたとき取得する。開いた履歴行のファイルも読み直す。失敗で部分的な書き込みが起きる場合も更新する。
- 履歴の比較元を既存の変更選択に追加し、読み取り専用で同じ変更タブへ渡す。スタッシュは可変の番号と取得したコミットIDを保持し、番号移動で別の内容を表示しない。
- 確認は既存の DSDialog で1枚にまとめる。削除・取り出しの確認に、プロジェクトのフォルダで実行中のセッションがある場合の注意を併記する。SessionNode.status と rawWorkspacePath を使い、worktree を除外する。キャンセルを既定とする。
- ⇧⌘R と ⌥⌘S は既存の Git 表示中だけの FocusedValue を介してメニューから呼ぶ。

## 理由と結果

利用順とグラフ追加取得の境界条件は [ADR 0209](0209-git-batch-order-and-history-continuity.md) で補う。現在のブランチを先頭に置き、改名前の切り替え履歴を現在名へ引き継ぐ。続きを読むは必要件数を先頭から再取得して一覧を置き換える。

既存サービス・更新通知・固定上部・1本のスクロールを再利用する。閉じた履歴の取得と本文の一括読み込みを避ける。マージ・リベース・衝突解消・変更の破棄は追加しない。
