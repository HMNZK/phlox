# ADR 0207: 競合の分離とindexの1項目に限定した操作

## 文脈

再レビューで、未マージのXYを通常変更へ分類する問題、削除行の操作が同名ディレクトリの子ファイルへ広がる問題、処理中の折りたたみ後に入力先が戻る問題を確認した。グラフのファイル展開部分でも線が途切れる。

## 決定

- 7種類の未マージXYを先に分離する。競合は別表示し、ターミナルなどでの解消を案内する。通常の一括／行ステージでは解決済みにせず、競合中のコミットを無効にする。
- 削除と改名元の削除は再帰指定のない `rm --cached --quiet` を使う。解除はHEADの完全一致するエントリを `update-index --add --cacheinfo` で復元し、追加の解除は再帰指定のない `rm --cached` を使う。`update-index` はpathspecではなく正確なパス引数を取るため、ここだけliteral pathspecを付けない。
- 行操作の完了時にも開閉を調べ、閉じていれば見出しへの入力先を維持する。
- 展開したグラフ行の下には、outgoingの到着レーンで縦線を描く。ファイルの個数や読込状態によらず展開領域の高さに追従させる。

## 理由と結果

既存のサービスと描画部品を使い、競合解消画面や新しいGit操作は増やさない。通常のファイル操作が他の行へ広がることを防ぎ、部分ステージの保護とGitの失敗理由を保持する。ADR 0205の出どころ別レコード保持と可視行だけの操作は維持する。
