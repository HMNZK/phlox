# ADR 0210: Git の区画間で行を区別し、変更タブの名前を固定する

## 文脈

実アプリで全区画と履歴行を開くと、グラフ内にコミット区画の行と空白が現れた。両区画の ForEach は同じコミットIDを使い、区画を含むIDは行内部の見出しにしか付いていなかった。また、変更タブの数字は作成順ではなく変更ファイル数だった。

## 決定

- 履歴の Section に区画ID、コミット行全体に既存の `GitHistoryRowID` を付ける。グラフとコミットの展開ファイルのAX識別子も分ける。展開状態と取得データの共有は維持する。
- 現在ブランチの先行数は0なら省略する。
- 変更タブとウィンドウ見出しは既存の `tab.changes` の日英文言を使い、変更件数を名前へ付ける挙動を置き換える。`AppLocalizedString` は日本語ではキーをそのまま返すため、日本語は「変更」、他言語は既存キーの翻訳を使う。

## 理由と結果

既存の行IDと表示関数を再利用し、新しい状態や設定を加えない。同一コミットを2区画で展開する画面外の描画・AX検査と、タブを繰り返し開閉するテストを追加する。
