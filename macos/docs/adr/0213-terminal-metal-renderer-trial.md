# ADR 0213: Metal 描画の切り替えを見送る

## 文脈

ユーザー用・エージェント用端末で共有する TerminalCoordinator に Metal 描画の切り替えを試験導入し、CoreGraphics と比較した。実機の Debug ビルドでは速度差が小さく、メモリ増加と文字幅の表示不良があった。

## 決定

Metal 描画の採用を見送り、CoreGraphics を継続する。試用の隠しキー `terminal.renderer`、TerminalRenderer、共通ビューの初回接続時の切り替え、Coordinator の設定読み取り、専用テストと追加依存を撤去する。ADR 0212 の Option＋左右矢印と端末応答の修正、および PTYKit は変更しない。

本 ADR の試用案を見送りに改めることは、今回の撤去依頼で明示された方針である。以下に試用結果を残す。

## 計測結果

2026-10-15 の実機計測記録 `/tmp/phlox-orch/metal-summary.md` から要点を転記した。Debug ビルドで各条件3回の中央値。今回の撤去作業で再計測した値ではなく、Release ビルドの性能は未検証である。落ち着くまでの時間は出力開始から、終了後メモリは終了12秒後の値。

| 出力 | 描画 | アプリ CPU 時間（秒） | 落ち着くまで（秒） | 最大メモリ（MB） | 終了後メモリ（MB） |
|---|---|---:|---:|---:|---:|
| seq | CoreGraphics | 1.62 | 1.8 | 214 | 214 |
| seq | Metal / perRowPersistent | 1.60 | 1.5 | 229 | 224 |
| seq | Metal / perFrameAggregated | 1.60 | 1.5 | 239 | 239 |
| cat | CoreGraphics | 1.83 | 2.4 | 214 | 214 |
| cat | Metal / perRowPersistent | 1.90 | 2.2 | 225 | 224 |
| cat | Metal / perFrameAggregated | 1.86 | 2.0 | 239 | 239 |
| yes | CoreGraphics | 2.49 | 2.3 | 214 | 214 |
| yes | Metal / perRowPersistent | 2.49 | 2.1 | 225 | 224 |
| yes | Metal / perFrameAggregated | 2.52 | 2.0 | 240 | 239 |

落ち着くまでの短縮は0.2〜0.4秒で、CPU 時間は同等。メモリはおおむね10〜25MB増え、最大メモリの差には26MBの条件もある。切り替えを維持する性能上の利点は確認できなかった。

## 表示の不具合

実機表示の確認結果は不合格だった。

- 文字がセル幅より詰まり、全角文字は約1.4セル分しか取られない。
- 英数字も右へ進むほど左へずれ、40文字で約2.5文字分のずれがある。
- 背景色とカーソルは正しい列にあり、文字位置と一致しない。
- 数字の端が少し欠ける。色と太字などは CoreGraphics と一致する。

## 再検討する条件

手元で使用する SwiftTerm の Metal 描画の文字幅・位置・欠けが上流で修正され、その修正を取り込めることを前提とする。全角と英数字、背景色・カーソルとの列の一致を実機で確認し、同条件の性能・メモリ再計測で切り替えを維持する利点が示された場合に、新しい ADR で再検討する。
