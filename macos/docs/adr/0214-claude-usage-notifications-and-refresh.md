# ADR 0214: Claude 使用量の通知と補完取得

日付: 2026-10-15。状態: 採用。ADR 0061 の取得順序を更新する。検証範囲と結果は修正計画の末尾に記録する。

会話中の `rate_limit_info.unifiedWindows` 通知を優先し、5時間・週次それぞれの有効な更新から60秒で不足を補う。能動取得は一度に1件、開始間隔60秒以上とし、失敗時は120/240/480/900秒待つ。キャッシュの読み直しは更新期限を延ばさない。期限切れは不明にし、架空の残量100%を作らない。

問い合わせ可能な標準認証のチャットがなければ、制御要求だけ送る専用Claude Codeを1本所有する。既存のstream-jsonトランスポート・使用量解析を再利用し、会話・ツール・履歴保存を使わない。チャットへの切り替え・個別取得オフ・自動更新オフ・アプリ終了で専用プロセスを閉じる。自動更新オフの初回だけは起動→取得→終了する。

使用率を持たない通知は無視する。設定変更と接続変更は待機を取り消して再計算し、MainActor上で直ちに旧結果の採用を止める。トランスポート終了待ちは既存の約1秒の上限に従う。枠ごとの状態番号と接続の識別子で遅れた応答を排除する。サーバー観測時刻が無いため、受信時刻をサーバー取得時刻とは呼ばない。

専用プロセスのメモリ単発観測は約467MiB。長時間の安定性は未検証。CLI互換性と認証に依存し、失敗は古い値の注記または不明表示にする。詳細な契約は `../specs/claude-usage-refresh-plan.md`。
