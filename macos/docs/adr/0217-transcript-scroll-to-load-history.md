# 0217: チャット履歴を最上部での追加スクロールから表示する

「以前のメッセージを表示」ボタンを廃止する。macOS の単一表示・グリッド表示で、最上部へ到達した後の上方向スクロールを契機に履歴を追加する。

- AppKit の実スクロール入力だけを扱う。上端に到達してからの上方向の入力を60pt分ためるとローダーを表示する。通常のスクロール、初期表示、プログラムによるスクロール、慣性は閾値に加算しない。
- 指を離すまで履歴を追加せず、ローダーを表示し続ける。ジェスチャー終了時に既存の窓と描画予算を1段階拡張する。終了通知がないマウスホイールでは入力停止180msを終了とみなす。1ジェスチャーにつき追加は1回。
- 上端の Comet ローダーは22pt・線幅2pt。透明→灰色→白のリングを0.9秒で1周させる。「視差効果を減らす」時は静止する。固定の300ms待ちは設けない。
- ローダーはネイティブの進捗表示として読み上げられる。VoiceOver の「以前のメッセージを読み込む」アクションは、閾値やジェスチャーを必要とせず履歴を追加する。
- 追加前の先頭ブロックへアンカーを戻す。上端を離れるスクロール・後続ジャンプ・セッション切替・画面離脱では保留中の追加を取り消す。セッション切替では操作中のジェスチャーも引き継がず、新しい操作開始から距離を数える。
- 非 Lazy VStack、初期件数、追加幅50、ブロック単位の予算は維持する。スクロール位置からレイアウトを連続計算しない。

ADR 0051 の「ボタンのみ」という操作の決定を上書きする。ADR 0030 のレイアウトから状態への再入禁止は維持する。iOS は対象外。

## 検証

`ChatHistoryLoadingTests` で、60ptの境界、操作中の表示維持、終了してからの追加、ホイール停止、単一表示とグリッドの位置保持、重複要求、上端離脱・セッション切替時の取消し、履歴末尾、読み上げの役割、静止リングの22pt描画を検査する。画面外ホストで本番の入力監視を取り付け、合成イベントのアプリ内配送から検査する。監視の自動取り付け自体はこのテストの検証範囲に含めない。パッケージの標準テスト入口から実行する。
