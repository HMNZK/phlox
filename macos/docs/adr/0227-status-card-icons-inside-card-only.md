# ADR 0227: エージェント状態カードの中に限り、作業のアイコンとタスクの完了印を戻す

日付: 2026-11-06。状態: 採用。[ADR 0144](0144-quiet-chat-chrome.md) をカードの中に限って置き換える。

## 文脈

ADR 0144 は、会話ログの作業カードから次の 3 つを外した。外した理由は、1 回の入力で数十件のカードが並び、装飾が本文より目立っていたことである。

- 種類のアイコン
- 回転する実行中表示
- 完了チェック

その後 [ADR 0226](0226-agent-status-card-derived-from-transcript.md) で、入力 1 回ごとのエージェント状態カードを入れることにした。カードのデザインは、ユーザーのスケッチと参考動画に従い、次の 3 つを前提にしている。

- 作業ごとの種類のアイコン
- タスクの ✓
- 見出しの動き

## 決定

1. **カードの中に限り、作業の種類のアイコンとタスクの完了印（✓）を戻す。**
   - ADR 0144 が問題にした「数十件のアイコン」は、カードでは起きない。作業はタスクの下に畳まれ、開いているのは進行中のタスクだけになるからである。
   - カードの外（承認・質問・Cursor の会話ログ）は、ADR 0144 のままにする。
2. **カードは `DisclosureCard` を使わず、別の部品で作る。**
   - `DisclosureCard` には、アイコンの引数（`systemImage` など）を戻さない。
   - ADR 0144 は、引数を残すといつでも復活できてしまうことを理由に、型ごと消した。その判断はカードの外では有効なまま保つ。
   - `AcceptanceQuietChatChromeTests` は変えない。
3. **動くものを増やさない。**
   - 動くのは、見出しの点描アニメーションと、進行中のタスクの印だけにする。
   - 作業の行ごとのスピナーは出さない。実行中は文字の薄さと「〜中」で表す。
4. **色は増やさない。**
   - アイコンと ✓ は、文字と同じ半透明グレーにする。完了を緑にしない（ADR 0042・0189）。
   - 完了したタスクは、取り消し線と薄い文字で非活性の見た目にする。

## 見送った案

- **`DisclosureCard` にアイコンの引数を戻して共用する。** 部品は 1 つで済む。しかし、カードの外でもアイコンを付けられる状態に戻り、ADR 0144 の判断がコードに残らなくなる。
- **カードでもアイコンを使わず、文字だけで作る。** ADR 0144 とは揃う。しかし、ユーザーが求める見た目（スケッチと参考動画）を満たさない。また、多数の作業の種類を一目で見分けられない。

## 影響

- 会話ログに、作業のアイコンの描き方が 2 通り残る。Claude・Codex はカード、Cursor は今の静かなカードである。
