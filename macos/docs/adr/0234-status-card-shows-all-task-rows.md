# 0234: エージェント状態カードはタスク行を全部表示する

## 背景

ADR 0231 の初回導入では、カードのタスク行を 8 行ずつ取得・表示し、更新のたびに進行中のタスクから始まる 8 行へ自動で移していた。そのため 3 つ目以降のタスクが進行中になると完了済みのタスクが表示から消え、「先頭のタスクに戻る」「さらにタスクを表示」「進行中の作業へ」を押さないと戻せなかった。利用者には、勝手にタスクが短縮される動作に見えた。

タスク行は題名・状態・時刻・件数だけの小さな要約で、1 回の入力で登録されるタスクは多くても十数件である。行を区切る必要は無い。

## 決定

- 画面は行一覧の続きカーソルをたどり、そのカードのタスク行を全部取得して全部表示する。行の表示範囲を切り替える操作と、手動で動かした行位置の保持は持たない。
- 実行サービスは行一覧を他の一覧と同じ件数上限（50 件）と応答容量上限で返す。8 行の専用上限は使わない。
- 8 行ずつ返す旧サービスにも、同じ続きカーソルをたどることで対応する。
- `chatCardRowsAround` は画面から使わない。1.14.11 の画面が送るため、実行サービスの受け付けは残す。

ADR 0231 のうち「手動の行位置を境界 ID で保持する」部分と「カード行を有限化しても進行中の行への直接移動と先頭への復帰を可能にする」部分をこの ADR で置き換える。タスク内の作業（新しい順に 30 件、FR-15）と、集約作業の詳細のページ分割は変えない。

## 結果

- 進行中のタスクが変わっても、表示されるタスクは変わらない。
- 行一覧の更新は、新しい実行サービスではタスク数が 50 を超えない限り 1 回の要求で済む。8 行ずつ返す旧サービスでは、タスク数を 8 で割って切り上げた回数の要求になる。
- 描画予算はカードの全タスク行を数える（行数の頭打ちをやめる）。
