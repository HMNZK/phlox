# Codex のスキル選択と更新通知

Codex の新規チャットでスキル候補を選ぶと、入力欄に `$<プラグイン名>:<スキル名>` の形で入り、native skill input として送信される。

## 更新通知と選択の保護

実機の Release と専用 Debug の両方で、選択成功直後の更新通知によって native skill input の送信が拒否された。通知は変更の可能性を示すため、通知だけを無視しない。

選択時にスキルのファイル一式の内容・相対パス・実行属性の SHA-256 を記録し、候補の再取得後に同じメタデータ・同じ内容を確認できた場合だけ選択を保持する。プラグインは共有参照もあるためプラグイン全体を対象にする。単独スキルはそのスキルフォルダを対象にする。内容は64KiBずつ読み、合計サイズでは制限しない。旧実装は合計8MiBを超えると照合できず、内容が変わっていなくても更新通知のたびに再選択を要求した。ファイルの変更・欠損、シンボリックリンク、読み取りエラー、4,096項目の上限超過、一覧取得エラーは従来どおり再選択を要求する。確認できないファイルを想像で同一扱いしない。

## 指紋を計算する時点（2026-11-06確認）

候補一覧の更新（`CodexSkillSelectionState.refresh()`）で、全候補の指紋をメインスレッド外で計算する。世代番号と取消しを確認してから、一覧と指紋を一緒に公開する。計算中は読み込み中かつ古い状態として、選択と送信を許可しない。画面へ渡す状態（`makeRuntimeSnapshot()`）は確定済みの値を返し、ファイルを走査しない。再取得後の照合にはこの更新時の指紋を使う。更新後のファイル変更は次の更新で反映し、それまでは送信直前の同一性確認で送信を拒否する。決定は[ADR0225](../adr/0225-send-acceptance-without-snapshot-wait.md)。
