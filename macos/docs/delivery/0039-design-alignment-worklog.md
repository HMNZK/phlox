# 0039: デザインの見本との食い違いを解消する worklog

> **書くもの**: 実装（0038）と見本（`specs/ClaudeDesign/`）を見比べて見つかった違いの一覧・判断・対応状況。
> **書かないもの**: 現行構成（→ `architecture/`）、要件（→ `specs/`）。

## 経緯

0038 の実装は設計書の文章どおりに動くことを確かめたが、見本の見た目と照らし合わせていなかった。2026-10-03 に見本の全状態（89 フレーム）を実装の写真（実画面 6 枚・画面外の描画 48 枚、`DesignSnapshotRenderTests`）とコードで見比べた。ユーザーの指示で全件を直す。

## 判断

- 見た目と文言は見本を正とし、見本では表せない挙動は設計書 §3.8 に従う。
- 端末名は、他の文言・版・状態をすべて縮めても収まらないときだけ、末尾を省略する。全文は読み上げとツールチップに残す。帯は文言 → 版 → 状態の印だけ → 端末名の順に縮め、状態だけを理由に版を隠さない。
- HTML の「外部の読み込みを止めています」は設計どおり残す。見本にない既存の子タブ記号・×・操作中区画の枠・エージェント管理項目は今回の対象外。
- 未保存確認の外枠・破棄ボタンは標準の NSAlert を維持。非表示では全体の描画が欠けるため、一覧を撮影し、題・警告・キー・ロケールはコードとテストで確認する。
- 4k・4l は比較用の代案で不採用。Markdown は面＋アクセントの輪（4j）を維持する。
- HTML のホバー下線は表示スタイルで付け、作者のインライン !important を尊重する。WebKit の画像と実物の説明・リンク先部品を合成し、ネイティブ外枠や標準 help の展開・実入力は未検証として区別する。
- チャットの既存表示は c7d9335 の独立採取画像と固定比較する。初回／後続の281画素・各1階調以内の差は、8bit・sRGB・1倍の CGContext へ条件を固定して解消。旧基準も保持し、許容差は追加しない。内部変換の原因は特定できず。
- シミュレーターの版は取得できた Xcode build・iOS runtime のみ表示。通信契約にない製品版・iOS build は固定値で補わない。
- 停止確認の件数は、この Phlox が登録した表示だけを数える（例「この Phlox の 2 タブ」）。別の版・Simulator.app の使用数は推測せず、停止の影響を本文で伝える。アイコンは既存の AppIconBadge を使用。
- Xcode 不在は xcrun --find simctl の終了コードと実行可否で判定し、DEVELOPER_DIR を尊重する。元の診断は保持し、本文に題を重ねない。端末を取得できなければ「停止中」と推測しない。
- 7q の端末外枠は不採用（7pを採用）。写真は偽の接続・単色 IOSurface で Phlox の帯・画面枠・案内を比較し、端末内の内容・OS の影と配置は対象外。
- スクリーンショットは、この Mac の SF Symbol 候補を画面外で比較し、閉じた角丸四角＋中央の丸が見本に近い circle.square を採用。輪郭と丸の比率は標準シンボルに従う。
- 本体チェックアウトの設計書は読み取り専用。端末名の省略条件は worktree 側 §3.8 と本記録を同じ表現へ揃える。
