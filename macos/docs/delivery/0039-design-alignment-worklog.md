## 経緯

0038 の実装は設計書の文章どおりに動くことを確かめたが、見本の見た目と照らし合わせていなかった。2026-10-03 に見本の全状態（89 フレーム）を実装の写真（実画面 6 枚・画面外の描画 48 枚、`DesignSnapshotRenderTests`）とコードで見比べた。ユーザーの指示で全件を直す。

## 判断（2026-10-03）

- 見た目と文言は見本を正とする。設計書 §3.8 は見本に合わせて改訂済み（停止の確認・送信中の帯・診断・フォルダの読込エラー・未保存確認の見出し）。
- 端末名は他の文言・版から先に縮めて残す。320pt で長い端末名と操作ボタンが収まらない場合に限り、最後に末尾を省略する（全文は読み上げとツールチップ）。無省略の固定幅では帯からはみ出すため、§3.8 を先に改訂した。帯の「外部の読み込みを止めています」は設計書どおり残す（見本 3d が描いていないだけ。5a には ○ 付きで描かれている）。
- 見本に描かれていない既存の要素（子タブの記号と ×、操作中区画の枠、「エージェント管理」項目）は変えない（今回の機能の外）。
- シミュレーターの版の欄は取得した Xcode build と iOS runtime を表示する。現在の通信契約には Xcode の製品版・iOS build が無いため、見本の番号を固定値で補わない。
- 停止確認の表示中タブ数は、この Phlox が登録している表示から数える。別の版・Simulator.app の使用状況は本文で影響を伝え、件数を推測しない。
- 再修正では本体側の未コミット設計書を worktree の `specs/embedded-ios-simulator.md` にコピーして改訂する。本体側は読み取り専用。停止確認の例文も実装の数え方に合わせ「この Phlox の 2 タブ」に変更。
- 帯は実際に収まる候補を選ぶ。文言の短縮 → iOS の版を隠す → 状態を印だけにする → 端末名の末尾省略の順とし、7i・7j2 という状態だけでは版を隠さない。
- Xcode 不在は一覧取得失敗時に `xcrun --find simctl` の終了コード・出力先の実行可否で判定する。`xcode-select -p` とディレクトリの存在だけでは Command Line Tools の選択を区別できず、`DEVELOPER_DIR` も尊重する必要があるため。生エラーは診断に保持し、本文には題を重ねない。
- 7q の端末外枠は不採用（見本の結論どおり 7p を採用）。写真の端末内の内容は偽の画面で代用し、Phlox の帯・画面枠・案内を比較する。ネイティブメニュー・シート・ポップオーバーは画面外で本物の内容を描き、OS が出す影・配置は比較対象外とする。
- 7k の「端末なし」には「停止中」を付けない（取得できた端末が無く、停止状態を確認できないため）。停止確認のアイコンは既存の `AppIconBadge` と実アプリの素材を使い、見本の花の絵を別部品で描き直さない。停止中の帯の「起動」は §3.8 の起動し直す案内と H5 に従って残す。
