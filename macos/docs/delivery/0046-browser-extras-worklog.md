## 判断

- ⌘F はメニューに置かず、WebView の `performKeyEquivalent` で、ページに入力先があるときだけ受ける。`CodeTextEditor` が keyDown で ⌘F を受けており、メニューのキーにするとエディタの検索を奪うため。
- 倍率は表示メニューの ⌘＋／⌘−／⌘0 を前面がブラウザのときだけ振り分ける（同じキーの二重登録を避ける）。
- 開発者ツールは見送り（2026-10-06 ユーザー判断）。`isInspectable` を入れて実アプリで右クリックしたが「要素の詳細を表示」は出なかった（公開 API では Safari の開発メニュー経由だけ）。右クリックに出すには非公開の設定が要るため、やめた。FR-10 は欠番。
