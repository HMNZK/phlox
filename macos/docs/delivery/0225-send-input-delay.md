# 送信後の入力欄待機を短くする

## 対象と判断

「Domainってどこでコピーできるの」と「Auth0の設定が終わりました」の送信後に入力欄が長く無効になった報告を調査した。Phloxの履歴登録からCodexの開始記録までは約0.02秒と0.28秒であり、ボタン押下からの時間は記録されていない。19:18の実行サービスのsampleでは、画面状態の作成中にスキルファイルの走査と変更検出計算がメインスレッドを占有した。GUIは1.14.5、実行サービスは1.14.4で、現devとの版差がある。発生時の遅延を完全再現したとは扱わない。

変更は[ADR0225](../adr/0225-send-acceptance-without-snapshot-wait.md)に従う。新しい状態モデルは追加せず、既存のスキル一覧、指紋辞書、更新世代を使う。状態取得を純粋な読み取りにし、送信受付だけを画面同期待ちから外す。共通コマンド列とスキル送信直前の検査は維持する。

## 検証記録

作業ツリーは`send-input-delay`。一時成果物はこの作業ツリーの`.verification/send-input-delay/`へまとめる。通常のRelease、Debugと実行サービスは停止しない。

製品4ファイルと回帰テストを変更した。スキル計算の非同期化、送信受付後の画面同期待ちの省略、同期による入力欄の再ロック防止を実装した。独立レビューで再ロック経路が1件見つかり、provider開始応答を保留するテストで修正前の失敗を確認してから修正した。新規接続時の編集可能状態も検査する。

- 修正前の機能テストは3関数・4引数例で想定したassertが失敗した。再ロックの追加テストも想定したassertで失敗した。記録は`.verification/send-input-delay/red.log`と`projection-red.log`。
- 同じ24プラグイン、各192参照ファイル、各32KiBの隔離fixtureで、修正前の実アプリはメインスレッドの指紋計算を検出して失敗した。修正版は更新中のsnapshotと通常送信、fakeへの1回だけの到達、全候補の指紋完成が成功した。両方のsampleが指紋計算自体を捕捉し、修正版ではバックグラウンドで捕捉した。これは画面入力遅延の改善率ではない。証拠は`native-baseline/`と`native-fixed/`。
- 固有IDアプリのDebugビルドと厳密な署名検査が成功した。CUAで`ChatComposer.input`へ送信後の次の下書きを設定し、AX値と実画面で表示を確認した。確認後は下書きを空へ戻した。実IMEとキー単位の遅延は未測定である。
- 最初の標準品質入口はexit 0。macOS19パッケージの成功ID5,657、XCTest8成功・1skip、iOS Swift Testing695件とXCTest402件、lint・build、必須fake13件が成功した。macOS通常段の任意skip23件とADR0209の既知問題1件を維持している。観測器の修正を正式適用した最終入力でも標準入口を再実行する。

## 実アプリ受入の観測器の修正

最初のlifecycle受入は、追加したCursor会話の再表示をAXで見つけられず失敗した。サービス側の4セッションと会話本文の保存、60秒の通信継続検査は成功していた。UIを操作しない再実行でも同じ箇所で失敗し、通常操作の影響だけでは説明できなかった。

既存の`accessibility_window_state()`は訪問済みAX要素の生ポインタを保存し、枝の配列を解放していた。別の枝でポインタが再利用されると既訪問と誤認する。同じGUIの同じセッション名に対して、従来版がfalse、探索終了まで訪問要素を保持する診断版がtrue、その直後の従来版が再びfalseになることを繰り返し確認した。証拠は`lifecycle-ax-comparison/logs/ax-comparison.jsonl`と同じ場所に保存した両関数のソース。

観測器は判定条件・探索上限・待ち時間を維持し、訪問した要素を探索終了まで保持する。製品側のセッション表示を、この誤観測に合わせて変更しない。同じPIDでのfalse→true→falseは57回記録できた。観測器は7行の変更で訪問要素を保持する。ポインタ再利用と成功・未発見・例外時の解放を確認するPython検査は、修正前に5件中2件失敗し、修正後は5件成功した。修正した観測器で全providerのlifecycleと60秒通信継続を実行し、exit 0となった。起動した10プロセスはすべて終了した。固定ソースの品質検査の完走後、2ファイルを正式適用し、実アプリ受入に使ったstage版とバイト一致を確認した。

中断から同じ会話への再送信は`stop-resume/`で成功し、起動した4プロセスの終了を所有記録で確認した。

## 最終レビューで確認した入力回収の競合

受付後に次の送信を許すと、先の失敗本文を回収・確認した直後に、後続送信の拒否による復元が本文を上書きする順序がある。本文と画像の両方を残す回帰テストを先に追加し、既存の下書き結合処理で回収済み入力の後へ拒否入力を結合する。送信時点の添付一覧を保持し、既に振り直された画像番号を再利用しない。

本文だけのケースと、両送信に画像番号1があるケースの2件を追加し、修正前に後続本文が失われることを確認した。回収による入力欄変更をUIの変更通知へも渡すため、画面を介した復元用マーカーの消失も検出する。

Claude状態モデルはhuman/anyとも既知一覧との比較でexit 0。anyに既知の停止通知による一時的な表示変化が残る。今回の独立実行の投影と下書き回収はモデルの対象外なので、この結果を本文回収競合の証明とは扱わない。

競合修正後の関連テストはSessionFeature33件、AppBootstrap24件が成功した。共有復元処理は直接clientの画像validation noticeを維持し、投影からの拒否だけに送信時の添付を渡す。最終の静的独立レビューは追加指摘なし。

## 最終候補の実アプリと機能別検証

`native-verified-build.log`のDebugビルドと厳密な署名検査はexit 0。最終の製品ファイルのSHAは`source-comparison.json`のfinalSHA256に記録した。`native-latest`のスキル更新中送信はexit 0で、指紋計算をバックグラウンドに捕捉し、メインスレッドでは捕捉しなかった。`lifecycle-latest`は全providerと60秒の通信継続、画面の正常終了・強制終了・差し替え後の継続と再表示がexit 0。起動した10プロセスを全て終了した。

`verify-phlox`の段1は`feature-unit-final/result.json`がok=trueで、送信・停止・再開・復元の全パターンが一致し成功した。スキルhelperは`.verification/send-input-delay/verify-phlox/`へ複製して本worktreeを指す配置を確認した。これはテストの範囲や期待値の変更ではない。

## 最終結果と後片付け

最終の標準品質入口はexit 0。結果は`.verification/send-input-delay/quality-20261106T112452673492/result.json`。macOS19パッケージの成功IDは5,659、XCTest8成功・1skip。iOSはSwift Testing695成功・XCTest402成功、lintとbuildも成功した。必須fake13件はskipなしで成功した。AX回帰を含むPython5件も成功した。macOS通常段の任意skip23件には別段で成功した必須fake13件を含む。ADR0209の既知問題1件、既存の未処理リソース・非推奨APIなどの警告は残る。無条件の全検査greenとは呼ばない。

最終アプリの`stop-resume-latest`もexit 0。全12回のnative診断・受入で、記録した所有プロセスの終了を確認した。終了後の複製アプリ、runtimeデータ、プラグイン素材、生成用ソースなど94ディレクトリをゴミ箱へ移した。`.env*`保護対象は0、使用中の対象は0。経路は`cleanup-result.json`に記録した。結果JSON、ログ、sample、受信状態の原記録と再実行用の診断コードは検証の証拠として保持する。共通managed-buildの出力は終了済みに登録し、既定のキャッシュ保持規則を維持する。

通常のRelease、Debug、利用中の実行サービスは終了・差し替えしていない。修正はdev由来の`send-input-delay`作業ブランチにある。実装完了時点ではコミットと統合を行わず、その後のユーザー指示でdevへの統合を進める。push、PR、mainへの統合、配布は今回の対象に含めない。

macOS専用lintと独立した静的解析は未設定。Swiftの型検査・コンパイル・リンクは標準テストとnativeアプリbuildで実施した。画面の描画構造は変更していないためデザイン見本との画像比較は対象外とし、入力可能状態をCUAのAXと実画面で確認した。実IMEと、報告された実セッションの押下からの遅延再測定は未実施である。モデル検査は投影・本文回収を対象にしておらず、その保証には使用しない。
