# Phlox 1.14.2（build 44）

準備中。2026-11-02の公開先確認で1.14.1/build43が既に配布済みと分かったため、既存配布物を置換せず、新しい版でmain統合後の修正を届ける。

基準ソースは `5de7602c5f9e9d5a3dbae4ff3acaabdbf2c9d708`。製品ロジックの追加変更は行わず、macOSの版/buildを更新する。日英リリースノートの正本は `release/notes-v1.14.2.md`。

手順は、版更新のコミット後に同じ固定ソースからMac配布物と照合用iOS配布物を生成し、署名・公証・来歴・入力・appcast・日英ノートを照合する。実機検査はユーザー指示により必須外であり、未実施を合格にはしない。品質ゲートと独立レビューを経て共通ツールでdev→verify→mainへ統合する。

公開時は、新しいGitHub ReleaseへDMGを添付し、phlox-distへ新しいSparkle ZIPを先に配置してからmainとappcastを公開する。既存タグ・既存配布物は書き換えない。普段使いのアプリは終了・入れ替えない。iOS版の公開・インストールは今回の対象外。

検証と公開の記録は、元リポジトリの `.verification/release-1.14.2-20261102/` に保存する。再現可能なコンパイル出力だけを専用worktree内のmanaged-buildで管理し、配布物・生記録とは分ける。性能上の未達・未検証事項は前回の応答性調査記録を維持し、本リリースのビルド成功を追加の性能測定とは扱わない。
