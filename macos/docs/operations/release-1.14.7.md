# Phlox 1.14.7（build 51）

`dev` に統合済みの変更を次の正式版として配布する。Mac の版を 1.14.7/build 51 に上げ、同じソースから署名・公証したアプリ、DMG、Sparkle ZIP を作成する。iOS も現行の配布照合ゲートに必要なビルドを同じ入力から作る。

主な変更は、大きな会話での起動・表示・履歴取得の負荷抑制、エージェント状態カード、iOS の入力欄と通知遷移の修正。利用者向けの文言は `release/notes-v1.14.7.md` を正本とし、英語・日本語を `site/appcast.xml` にも載せる。

作業ブランチから `dev`、続いて `main` への統合には共通マージツールを使う。`main` の必須ゲートでは新しいソースから作成した Mac/iOS 配布物と検証記録を照合し、旧 1.14.6/build 50 の配布物は流用しない。ただし今回の実機検証は[例外記録](physical-verification-exception-v1.14.7.md)のとおり未実施とし、配布物の検証までを必須とする。検証成功後に GitHub Release、Sparkle ZIP、更新フィードを公開し、配布 URL と更新の整合を確認する。

アプリ更新では実行中の常駐サービスは置き換わらない。現在利用中のセッションを止める前に状態を確認し、別途合意した時点でサービスを切り替える。
