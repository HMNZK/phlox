# Phlox 1.14.8（build 52）

長い会話での状態カードと入力履歴、作業状態・経過時間の表示を修正したmacOS版を配布する。利用者向けの内容は`release/notes-v1.14.8.md`を正本とし、同じ内容を英語・日本語でSparkle更新フィードにも掲載する。

作業ブランチ→dev→mainは共通マージツールを使う。今回の差分に対応する独立シナリオレビューを取得し、統合候補上の全体品質・セキュリティ検査を省略しない。Mac 1.14.8/build 52のDeveloper ID署名・公証・staple済みapp/DMGと、同じappから生成した最終Sparkle ZIPを作成する。main前の照合用iOS候補は1.0/build 21とし、既存のiOS配布先の公開は含めない。

証拠と実配布物は統合作業を行うworktreeの`.verification/release-evidence/1.14.8/mac52-ios21/`へまとめ、参照している間はそのworktreeも保持する。配布物に結び付くビルド入力・有効設定・ハッシュ・署名・実機記録を照合する。旧版の実機省略例外は1.14.7の固定成果物だけに適用され、本版へ流用しない。未実施の実機シナリオを合格として記録しない。

公開は、上記検査とdev→main統合が成功してからGitHub Release、Sparkle ZIP、更新フィードの順で行い、配布URL・版・署名・Pages反映を確認する。使用中のアプリや常駐実行サービスは自動で終了・差替えしない。旧サービスで実行中のセッションは継続し、新しいカード取得機能はサービス更新後に有効になる。

現在は準備中。ビルド・実機・公開の結果は実行後に追記する。
