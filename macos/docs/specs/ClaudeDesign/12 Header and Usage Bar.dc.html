ヘッダーと使用量のバー
ヘッダーから「対応待ち」ボタンと使用量のチップを消し、単体／グリッドの切替をインスペクタの切替の左に寄せる。使用量はウィンドウの一番下の全幅のバーに移す。タブの構成は 11 Project Tabs の案のまま描いた。
バーの決まり
1
高さ 24pt・11pt・副文字色。地はツールバーと同じ色、上に区切り線。サイドバーの下まで通して、ウィンドウの最下段を 1 本の帯にする。単体でもグリッドでも、インスペクタを開いていても出す（FR-34・FR-38）。
2
ハーネスごとに「ロゴ　枠 残り%（リセットまで）・枠 残り%…」。ハーネスの間は 18pt 空ける。ロゴは 12pt。Claude と Codex のロゴはバーの文字と同じ副文字色の単色、Cursor は元の色のまま。略号（Cl・Cx・Cu）は使わない。
3
残り 20% 未満は注意の色の文字＋semibold（ダーク #F4BD68・ライト #8A5300）。▲ などの印は使わない。読み上げに「残りわずか」を含める（FR-36）。取得できないハーネスは「取得できません」を副文字色で。
4
狭いときの省き方: 1100pt 未満でリセットまでの時間を省き、600pt 未満で枠の名前を省く。数値は省かない（FR-37）。720pt では 1 段目で収まる（U3）。2 段目は U7。
5
バー全体が 1 つのボタン。押すとインスペクタの使用量を開く。ホバーで灰色の面、キーボードのフォーカスで内側に 2pt の枠（U6）。
U. 描き分け
U1単体表示 · 1440pt（ダーク）
ヘッダー（38pt）は左に信号、右に単体／グリッドとインスペクタの切替だけ（サイドバーの開閉はサイドバーを隠したときだけ出す）。「対応待ち」ボタン・使用量のチップ・対応待ちの一覧は無い（FR-32）。最下段のバーに 3 つのハーネスの全枠の残り。
U2グリッド表示
切替はグリッドが選択中。下段のタブ列は出さず、タイルは会話だけ（PE8）。タイルの見出しは題名だけで状態は出さない（D19）。フォーカス中のタイルに藍の 2pt の枠。バーは単体と同じ位置。
U3最小幅 · 720pt
リセットまでの時間を省き、枠の名前と数値を残す。3 つのハーネスが 1 行に収まる（FR-37）。
U4残りわずかの枠と、取得できないハーネス
Claude の 5 時間枠が残り 12%（38 分後にリセット）で、注意の色の文字・semibold。Cursor は「取得できません」。読み上げは「使用量。Claude 5時間 残り 12%、残りわずか、38分後にリセット、週次 残り 40%。Codex 5時間 残り 99%、4時間後にリセット、週次 残り 85%、5日後にリセット。Cursor 取得できません」。
U5ライト · 単体表示
バーの文字はライトの副文字色 #5B5B60（地 #F6F6F7 に対して約 6:1）。Claude と Codex のロゴも同じ色。
U8ライト · 残りわずかの枠と、取得できないハーネス
残りわずかの枠はライトの注意の色 #8A5300・semibold（地 #F6F6F7 に対して約 6.0:1）。「取得できません」は副文字色。
V. バーだけを拡大
U6通常 / ホバー / キーボードのフォーカス（ダーク・ライト）
ホバーは今のボタンと同じ灰色の面（主文字色の 5〜6%）。フォーカスは不透明な 2pt の枠（ダーク #959CD0・ライト #3B469B）。ツールチップ「インスペクタで使用量を開く」。
U7省き方の 3 段階（幅 1440 / 900 / 520）
1 段目でリセットまでの時間を、2 段目で枠の名前を省く。残りわずかの色と「取得できません」はどの段でも残る。520pt はウィンドウの最小幅より狭く、実際には起きない幅（省き方の確認用）。

確かめたこと
文字のコントラスト: 副文字色はダーク #ABABB1 / #2A2A2D で約 6.8、ライト #5B5B60 / #F6F6F7 で約 6.2。残りわずかの色はダーク #F4BD68 で約 8.9、ライト #8A5300 で約 6.0。どれも 4.5:1 以上。
略号・図形・ハーネスの色: 無い。ハーネスはロゴで分かり、読み上げでは名前を言う。
ロゴの色: Claude・Codex はバーの文字と同じ副文字色にした（チップでは主文字色）。バーの中で文字より目立たせないため。主文字色に揃える場合は指示がほしい。
