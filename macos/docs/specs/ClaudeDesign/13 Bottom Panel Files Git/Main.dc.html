下部パネル・ファイル操作・Git タブ
今の画面（11 Project Tabs・12 Header and Usage Bar・2 File Tree・6 Unsaved Changes）に 3 つの要素を足した。寸法と形は見本に合わせ、色は ADR 0189 の白黒のアクセント。使用量のバーは押せないまま。macOS 標準のメニューはシステムの見た目で描いた。ハーネスのロゴはこのモックでは名前の文字で仮置き。
各ボードの末尾にそのボードの要件対応表がある。全番号の表は QA のボード。
ボードの一覧
W ウィンドウ全体
1600 × 1000pt で 3 つの要素の置き場所に番号を付けた全体図。閉じた状態、窓の幅 1000pt の重ね表示、グリッド 4 枚、左右分割と通しのパネル。
D 下部パネル
見出し「下部パネル」・外側の枠・13pt。状態 9 種、ウィンドウの中で 7 枚（最小・最大・200pt の決まり・切り替え・無効）、「表示」メニュー。
FT ファイルツリーの操作
システムのメニュー 5 種・その場の入力 7 種・操作の後と失敗・ゴミ箱の確認 5 種。
GT Git タブ
状態 15 種、260 / 280 / 340pt と重ね表示。
QA 横断点検
要件の全番号の置き場所、キーボードだけの手順、VoiceOver、コントラスト、英語、ライトテーマ、直した点。
部品
PhloxWindow・BottomPanel・FileTreeOps・GitTab・TrashAlert。各ボードはこの 5 つを読み込んで描いている。
決まったこと（2026-10-14）
開閉ボタン
ヘッダーの右端（単体／グリッドとインスペクタの開閉の間）。P6 の書き換えは要件側で行う。
見出し
「下部パネル」（VoiceOver も同じ）。
キー入力の印
パネルの本体の外側の枠（ライトでも 3:1）。
文字
子タブのターミナルと同じ設定（既定 13pt）。
高さ
最小 120pt。最大は中央の 70% と上の区画に 200pt を残す高さの小さい方（左右分割も同じ）。
キー
⌃`（US 配列）・⌥⌘N・⇧⌥⌘N・⌘↓。ツリーの Return は名前の変更。「表示 › 下部パネルのシェルを再起動」を足す。高さのキーは足さない。
メニュー
右クリックなどの macOS 標準のメニューはシステムの見た目。アプリの中の選択は 24% の塗り。
重ね表示
中央が 480pt を割ったとき（窓の幅およそ 1022pt 未満）。カードがパネルの見出しを隠してよい。
グリッド
選択中のタイルは今の見た目のまま（2pt のアクセントの輪）。
ファイル操作
確認はふだん軽い形、未保存の変更を失うときだけ取り返しがつかない形。件数は 1,000 項目まで。同名はファイル / フォルダを言い分ける。.git と .DS_Store はツリーに出ない。
Git タブ
種類は 1 文字（A・M・D・R・U）。行番号は 300pt 以上。長い差分は 60 行。
確定版（残りの確認事項はなし）
右クリックのメニュー — ↩ は出さない（Return はツリー・一覧が受ける）。使えない項目は淡色で、先頭の見出しで対象を示すだけ。
ゴミ箱の確認 — 6 と同じシートの NSAlert。軽い形は削除の色を使わず、既定のボタンは「ゴミ箱に入れる」、⌘⌫ は効かせない。
シェルを再起動のメニュー — 一度でも起動していれば閉じていても使え、押すと開く。一度も起動していなければ無効。
選択中のタブの名前 — サイドバーの開閉のすぐ右。グリッド表示では出さない。
描いていないもの（§7）
下部パネルにターミナル以外を出すこと・パネルの中の複数ターミナル・子タブのターミナルとの相互移動。共通ターミナル（ADR 0187 で廃止）。
ファイルのドラッグ＆ドロップ・複製・複数選択・一括操作・取り消し（⌘Z）。
Git タブでのステージ・コミット欄・破棄・ブランチ切り替え・push・PR。
設定の「ターミナル › シェル」（§3。依頼不要）。BS-4 はターミナルと見出しの表示だけ描いた。
「変更」の子タブそのもの（今の画面のまま。開く入口だけを描いた）。
