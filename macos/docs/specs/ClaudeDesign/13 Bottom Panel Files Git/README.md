## 決まったこと（2026-10-14）

- 開閉ボタン: ヘッダーの右端（単体／グリッドとインスペクタの開閉の間）
- 見出し: 「下部パネル」（VoiceOver も同じ）。キー入力の印は本体の外側の枠（ライトでも 3:1）
- 文字: 子タブのターミナルと同じ設定（既定 13pt）
- 高さ: 最小 120pt。最大は中央の 70% と上に 200pt を残す高さの小さい方（左右分割も同じ）
- キー: ⌃`（実装では ⌘J に変更。ADR 0200）・⌥⌘N・⇧⌥⌘N・⌘↓・⌘⌫。ツリーの Return は名前の変更（メニューのキーにはせず、ツリーが受ける）
- 「表示 › 下部パネルのシェルを再起動」: 一度でも起動していれば閉じていても使え、押すと開く。一度も起動していなければ無効
- メニュー: macOS 標準のメニューはシステムの見た目。↩ は出さない。使えない項目は淡色で、先頭の見出しで対象を示すだけ。アプリの中の選択は 24% の塗り
- ゴミ箱の確認: 6 と同じシートの NSAlert。ふだんは軽い形（削除の色なし・既定は「ゴミ箱に入れる」）、未保存の変更を失うときだけ取り返しがつかない形（既定は「キャンセル」）。⌘⌫ は確認の中で効かない。件数は 1,000 項目まで
- 重ね表示: 中央が 480pt を割ったとき（窓の幅およそ 1022pt 未満）
- ヘッダーの選択中のタブの名前: サイドバーの開閉のすぐ右。グリッド表示では出さない
- グリッド: 選択中のタイルは今の見た目（2pt のアクセントの輪）
- Git タブ: 種類は 1 文字（A・M・D・R・U）。行番号は 300pt 以上。長い差分は 60 行
