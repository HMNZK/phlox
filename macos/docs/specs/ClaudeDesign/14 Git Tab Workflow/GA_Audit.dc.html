見つかった穴 1：「プッシュ」にキーが無かった。macOS の「キーボードで操作」が切り（初期設定）だと Tab はボタンに届かないので、マウスなしではプッシュできなかった。→ ⌥⌘P と Git メニューの「プッシュ」「PR を作成」を足した。
見つかった穴 2：GK の手順 7「Tab Tab でプッシュへ」は誤り。コミットした後の「コミット」は押せないので Tab で飛ばされ、1 回で届く。→ 手順を ⌥⌘P に直した。
見つかった穴 3：既定がキャンセルの確認（D4〜D7）で、操作のボタンにキーで届く道が書いてなかった。→ D8 を足した。
決めたこと：作成・スタッシュ・切り替えの後は、入力先をできた行（新しいブランチ・stash@{0}）に置く。取り出しの後は、スタッシュ区画の見出しに戻す。
