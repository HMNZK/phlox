提案: 線の幅
線の間隔 10pt・線の太さ 1.5pt・点の直径 7pt（マージの点は 8pt で輪を太く）。4 本で 46pt。5 本目からは間隔を 8pt に詰め、7 本を超える線は右端の 1 本にまとめて点線にする（どの線かはツールチップ）。
色は使わず濃さで分ける：今のブランチの線と点は主文字色、ほかの線は副文字色。HEAD の点だけ塗りつぶす。区別の決め手は線の位置と札で、色ではない。
提案: 札の省略
1. ローカルとリモートが同じコミットなら 1 枚に。main と origin/main は「main」＋雲の印。ツールチップ「main · origin/main」。
2. リモートだけの札は破線の枠＋雲の印で、名前から origin/ を外す。
3. 長い名前は最後の段だけ残す。feature/git-tab-workflow →「…/git-tab-workflow」。札の幅は最大 112pt、それでも長ければ末尾を省く。
4. 札は 2 枚まで。3 枚目からは「+2」にまとめ、ツールチップに全部。タグはタグの印を付けて省略しない（v1.10.0）。
5. 今のブランチの札は太字と主文字色の枠。要約は最低 24pt を残し、残りは札より先に省く。
操作
行を開く・押す・右クリック（ID をコピー・ここからブランチを作成）はコミット区画と同じ（GW-7）。最初は 200 件、末尾で続きを読む。VoiceOver は線を読まず、「要約、ブランチ main、origin/main、HEAD、短縮 ID」の順に読む。
