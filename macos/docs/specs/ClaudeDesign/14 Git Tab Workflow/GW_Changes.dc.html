C. 「変更」の子タブ（GW-5・GW-6）
左の一覧とコミット欄を無くし、Git タブで押した 1 ファイルだけを出す。ツールバーは 40pt に 1 行：「差分｜内容」・ファイル名（SF Mono 12pt）・フォルダ（11pt 副文字色、先頭を省く）・出どころの札（角丸 4・枠 14%）・行数・右端に「ファイルタブで編集」。本体は SF Mono 12pt / 20pt、行番号 1 列（追加は新しい番号、削除は元の番号）と記号の列、追加・削除は色と「+」「−」の両方で分かる。今の画面の「エディタ」の行は、Git タブの更新と重なるので無くした。
B1何も選ばれていない
「変更」の子タブを手で開いたとき、選んでいたファイルが消えたとき（コミットした・破棄された）、アプリを開き直したとき。
中央に「Git タブで変更を選んでください」と、Git タブを出すキー（⇧⌃⌘G）。「差分｜内容」と「ファイルタブで編集」は淡色で押せない。
Git タブの一覧は選択なし。行数がそのまま見える。
B2ステージ済みの行を押した
「ステージ済み」の GitCommitBar.swift を押した。行の右は「−」（ステージを外す）。
中央の札は「ステージ済み」（git diff --cached）。同じファイルが両方のグループにあるとき（GitTabView.swift）は、押した側の差分を出し、札で見分ける。札にホバーで「ステージ済みの変更（git diff --cached）」。
新しいファイルは 1 行目から全部が追加の行。
