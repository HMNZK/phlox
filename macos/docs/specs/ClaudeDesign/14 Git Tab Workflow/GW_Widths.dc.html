推奨: 上部は固定（R1）
1. 主な往復が上と下をまたぐ。「＋」で選び、メッセージを書き、「コミット」。一覧を下へ送っても「コミット」と理由の行が見えている。
2. エージェントの書き換えで一覧が伸び縮みする。流す形だと、書いている途中のメッセージ欄が一覧の増減で上下に動く。固定なら動かない。
3. 失敗の表示を見落とさない。流す形では、下を見ている間にプッシュの失敗が画面の外に出る。
代わりに払うもの。一覧の高さが 148pt（メッセージ 1 行のとき）減る。838pt なら区画に 600pt 余り残る。メッセージ欄は 5 行で止め、区画の見出しを貼り付けて位置を見失わないようにする。
窓が低いとき（案）。Git タブの高さが 520pt を割ったら、メッセージ欄の上限を 3 行に下げる。それでも固定欄は流さない。
