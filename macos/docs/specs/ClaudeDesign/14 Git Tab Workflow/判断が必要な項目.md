## C. 残っている問題・注意

1. **表示の確認をしていない。** モックはこちらで描画して見ていない。崩れ・重なりがあれば知らせてほしい。
2. **英語の幅は見積もり。** SF Pro の字幅からの計算で、実装では ±10% ずれる。英語の画面は描いていない。
3. **ライトは Git タブ・ウィンドウだけ。** 確認ダイアログ（GitConfirm）はダークだけ。
4. **VoiceOver のカスタムアクションは HTML では表せない。** GK の表が正本で、モックの aria は読む順の見本。
5. **「＋」の縁は入力先 24% の行の上では 2.36:1。** 記号自体は 10:1 なので識別はできるが、縁は 3:1 を割る。
6. **メニューに ↩・Space を書かない（以前の決定どおり）。** その代わり行のツールチップに書いている。
7. **入力欄の縁を 40% にしたのはモックの GitPanel だけ。** DesignSystem 側の値は未変更（A1 の判断待ち）。
8. **「変更」タブの構文の色（コメント #8D99A5 など）はモックだけの仮の値。** 実装の構文色の正本に合わせる必要がある。
