# 用語集

> **このファイルの役割**: Phlox のドメイン用語の定義と、使わない言い換え。
> **書かないもの**: 実装・型名・画面の作り（→ architecture/・adr/）。

## エージェントの作業

**タスク**:
エージェントが自分の判断で登録する作業の単位（Claude の Tasks・TodoWrite、Codex の計画）。追加・削除・状態の変更はエージェントだけが行い、ユーザーは変更をエージェントに依頼する。Phlox は登録を強制しない。
_Avoid_: ToDo、ステップ、プラン項目

**タスクリスト**:
1 回の入力の中でエージェントが登録・更新したタスクの並び。前の入力のタスクは含めない。入力を巻き戻すと、その入力のタスクリストも消える。
_Avoid_: プラン、計画、ToDo リスト

**作業**:
エージェントが行う個々の操作（ファイルの読み込み・検索・編集・コマンド実行など）。進行中のタスクがちょうど 1 件のときに行われた作業はそのタスクに属し、それ以外はタスク外の作業になる。
_Avoid_: ステップ、ツール呼び出し、アクション

**タスク外の作業**:
どのタスクにも属さない作業。タスクの登録前・合間・タスクを作らない入力での作業と、進行中のタスクが複数あるときの作業がこれに当たる。
_Avoid_: その他、未分類

**サブエージェント**:
エージェントが作業を任せるために起動する子のエージェント。起動時に進行中のタスクがちょうど 1 件なら、その作業はそのタスクに属する。
_Avoid_: 子セッション、ワーカー
