# アプリ内ブラウザ

## 0. 要点

中央の子タブで Web ページとローカル HTML を開く。CDN の JavaScript を使うスライドを表示できる。表示中のページは既定のブラウザで開き直したり、エージェントに伝えたりできる（2026-10-06 追加）。ファイルプレビューとは別の機能で、ADR 0178 の制限は変更しない。

## 1. 機能要件（FR）

| ID | 要件 |
|---|---|
| FR-1 | ＋メニューと ⌃⌘R でブラウザを開く。セッションごとに 1 タブ |
| FR-2 | 戻る・進む・再読込／中止、URL 欄、ページタイトル、読み込み状態を帯に表示 |
| FR-3 | http/https、絶対パス、file:// を入力できる。スキームなしは https。空入力は移動しない |
| FR-4 | HTML ファイルタブの「ブラウザで開く」で、その保存済みファイルを開く |
| FR-5 | target=_blank と window.open は同じタブ。alert/confirm/prompt とファイル選択は標準パネル |
| FR-6 | 失敗時は理由と再読込を表示 |
| FR-7 | 帯の「既定のブラウザで開く」で、表示中のページを macOS の既定のブラウザで開く。ローカル HTML も同じブラウザで開く（2026-10-06 追加） |
| FR-8 | ページ内検索。帯の虫めがねと ⌘F（ページにフォーカスがあるとき）で、帯の下に検索欄を出す。Enter で次、⇧Enter で前、末尾から先頭へ折り返す。見つからなければ「見つかりません」。Esc か「完了」で閉じてページにフォーカスを戻す（2026-10-06 追加） |
| FR-9 | 拡大・縮小。ブラウザを前に出しているとき、表示メニューの ⌘＋／⌘−／⌘0 はページの倍率を変える（他の子タブでは従来どおり文字サイズ）。倍率は 50%〜300% の段階で、タブを閉じると戻る。100% 以外のときは帯に倍率を出し、押すと 100% に戻す（2026-10-06 追加） |
| FR-10 | 開発者ツール。ページの右クリックメニューに WebKit の「要素の詳細を表示」を出し、Web インスペクタを開ける。専用のボタンは置かない（WebKit に開く公開 API が無いため）（2026-10-06 追加） |
| FR-11 | 帯の「エージェントに伝える」で、`参照中のページ: <タイトル>（<URL>）。Phlox のブラウザで表示中です。` をそのセッションの入力欄に入れる。ローカル HTML は URL の代わりにファイルのパスを入れる。タイトルが無ければ URL（パス）だけ。入れ方・入れられないときの扱い・会話のタブを前に出すことはシミュレーターの FR-10 と同じ（会話はブラウザでない方の区画に出す）（2026-10-06 追加） |

## 2. 非機能要件（NFR）

- JavaScript は有効。タブごとに非永続の WKWebsiteDataStore を使用し、閉じると破棄する。
- ブラウザタブ・URL・Cookie・ログイン情報を保存しない。旧版のタブ配置の読み込み互換性を維持する。
- ユーザーが入力／選択したページとその遷移・リソースだけを読み込む。自動で初期ページを開かない。
- ローカル読み取りの許可は明示的に開いたファイルの親フォルダ。範囲内の移動では許可を保つ。許可外へのページ遷移は拒否し、URL 欄からの明示的な入力を求める。
- 既存の DesignSystem の色・字体・余白・ボタンを使用する。

## 3. 設計

### 3.1 所有と表示

AppRouter がセッションごとの BrowserTabModel を非永続で所有する。モデルが WKWebView と delegate を保持し、表示から隠れても履歴を保つ。閉じるとモデルを除き読み込みと delegate を解除する。

### 3.2 URL の解釈

前後の空白を除く。絶対パスは file URL に変換し、`#` 以降を fragment として扱う（`/tmp/slides.html#/2`）。`~/` はホームフォルダに展開する。file URL はローカルの絶対パスに限る。http/https には host が必要。他スキームは拒否する。localhost:ポートも https 補完の対象。検索への転送はしない。

### 3.3 WebKit

非永続データストアを使用し、ローカルファイルは loadFileURL(_:allowingReadAccessTo:) で明示的に開いたファイルの親フォルダを許可する。遷移先は http/https と許可範囲の file に限定する。主フレーム以外では、ページが作る about:・data:・blob: も許可する。許可範囲内のファイル移動では範囲を変えない。許可の変更は主フレームの読み込みが確定した didCommit で反映し、http/https では解除する。確定前の失敗・中止では表示中のページの許可を保つ。HTTP iframe を含む外部ページから file への移動はリンク・window.open・target=_blank とも取り消し、URL 欄等から明示的に開く操作だけを許可する。許可外のスキームは移動を取り消すだけで、ページを残し外部アプリにも渡さない。

ページの右クリックの「要素の詳細を表示」を出すため `isInspectable` を有効にする（FR-10）。インスペクタはそのページの内容を見せるだけで、許可範囲・データストアは変えない。

ダウンロード要求と表示できない応答は拒否し、主フレームの場合だけ「ダウンロードには対応していません。」と表示する。拒否後の WebKitErrorDomain 102 はこの文言を上書きしない。ページ内の fragment 移動・読み込み失敗後にも移動待ち状態を解除し、pushState／replaceState に URL 欄を追従させる。アプリの内部操作を呼び出す JavaScript ブリッジは設けない。

戻る・進むの操作では WebKit の履歴項目を使う。移動先が現在の許可範囲内なら範囲を保ち、範囲外のファイルなら移動先の親フォルダを許可する。変更は didCommit で反映する。別フォルダを明示的に開いた後も以前のページへ戻れる。

HTTP のページを開くため、Info.plist の NSAppTransportSecurity に NSAllowsArbitraryLoadsInWebContent = true を設定する。WebView にだけ適用し、URLSession の制限を緩める NSAllowsArbitraryLoads は設定しない。ファイルプレビューは引き続き独自スキームと外部遮断ルールを使う。

### 3.5 永続化

シミュレーターと同様、保存用コピーから .browser を除く。右が一時タブなら除去、左が一時タブなら残った右を昇格、なければ会話。分割が消えたら右フォーカスを解除する。実行中の配置は変更しない。

### 3.6 ショートカット

⌃⌘R を開く操作に使う。⌃⌘B はファイルツリーと衝突するため使わない。⌘F はページにフォーカスがあるときだけ WebView が受ける（メニューには置かない。ファイルのエディタが自分で ⌘F を受けているため、メニューのキーにすると奪ってしまう）。⌘＋／⌘−／⌘0 は表示メニューの既存の項目を、前面がブラウザのときだけページの倍率へ振り分ける。

### 3.8 見た目

見本は `ClaudeDesign/9 Browser Tab.dc.html`。帯は既存の 30pt。戻る・進む・再読込／中止を左、URL 欄を伸縮領域、ページタイトルを右に置く。URL 欄の右に、倍率（100% 以外のとき）・虫めがね（ページ内検索）・既定のブラウザで開く・エージェントに伝えるを置き、その右にタイトル。3 つのボタンはページを開いていないときは押せない。狭幅ではタイトルを省略し、URL 欄と操作を残す。検索欄は帯の下に 30pt の行で出す。空状態は「URL またはファイルのパスを入力」、失敗は「ページを開けません」と理由・再読込。ライト／ダークに追従する。HTML の帯では既存の再読込に隣接してブラウザボタンを置く。幅が足りないときは、補助の文言（「閲覧のみ」など）より先にブラウザボタンをアイコンだけにする（状態の表示を残すため。2026-10-06 PM、UI テストで「閲覧のみ」が消えることを確認して変更）。

## 4. 互換性

ADR 0178、既存 HTMLPreviewView のスクリプト禁止・外部遮断、ファイルの保存・競合処理は維持する。ブラウザは保存済みの内容を読む。entitlements は本体の sandbox が無効であるため変更しない。

## 5. テスト計画

- 単体: URL 解釈、ローカル許可範囲、保存時の左右昇格と旧版互換、HTML からそのファイルの URL で開くこと、WebView の非永続・JavaScript 設定。
- 描画: 空・読み込み中・ローカル表示・失敗 × ライト／ダーク、狭幅、HTML の入口を画面外で撮影して見本と比較。
- UI: テストで作ったローカル HTML の JavaScript による文字変更と ⌃⌘R を検査。ネットワーク非依存。PM が実走する。
- 回帰: ページ所有 iframe、子フレーム／主フレームのダウンロード、許可外リンク、fragment 後の履歴更新、ローカルから HTTP への許可解除、HTTP から file への拒否を画面外の WebKit と LocalHTTPServer で検査する。ブラウザの文言は App の日本語キー／英訳カタログに登録する。
- 追加分（2026-10-06）: エージェントに伝える文（タイトルの有無・制御文字の除去）、倍率の段階と上下限、`isInspectable`、ページ内検索の次／前／見つからない（画面外の WebKit）、会話をブラウザでない方の区画に出すこと、帯と検索欄を画面外で撮影して見本と比較。
- 既定 Swift テスト、DashboardFeature 全数、Debug ビルドを実行。
- 回帰: 子フォルダから親へのリンクと戻る・進む、HTTP iframe から file への window.open／target=_blank の拒否、HTTP 移動の失敗・中止時の許可維持を検査する。

## 6. 範囲外

| 項目 | 理由 |
|---|---|
| ダウンロード | 保存先・進捗・寿命の管理が追加で必要 |
| 拡張機能 | 最低限の HTML 閲覧に不要 |
| ログインの保持・複数タブ・履歴・ブックマーク | 保存するデータの扱いが追加で必要（2026-10-06 ユーザー判断で見送り） |
| ブックマーク・履歴の保存 | 非永続の方針と異なる |
| 検索エンジン転送 | URL／ファイルを開く用途に限定 |
| 未保存 HTML の転送 | 下書き配信とローカル読み取りを二重管理しない |
