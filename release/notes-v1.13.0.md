# Phlox 1.13.0

## New

- New chats suggest skills and enabled plugins for the selected agent, including Codex and Claude Code skills.

## Fixed

- Skill suggestions now match text anywhere in the name. Cached results appear promptly as you type.
- A chat interrupted by Codex no longer stays marked as running, and its completion indicator clears when you return to it.

## 新機能

- 新規チャットで、選択したエージェントのスキルと有効なプラグインを候補に表示します。Codex と Claude Code に対応しています。

## 修正

- スキル名の途中にある文字でも候補を検索できます。取得済みの候補は入力中すぐに表示します。
- Codex の中断後に実行中の表示が残る問題と、会話に戻った後も完了マークが残る問題を修正しました。
