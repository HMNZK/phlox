# Phlox 1.14.0

## New

- Sessions keep running when you quit, update, or restart Phlox. When Phlox opens again, it reconnects to them, including pending approvals and questions.
- The grid can arrange tiles in sidebar order, and you can restore your custom layout.
- You can rename paired iPhones.
- Codex asks questions with question cards, so you can answer by picking an option.
- Scroll past the top of a chat and release to load earlier messages.
- Chats in progress use the same model, permission, and Plan cards as new chats.

## Fixed

- Links and openable files in chats and Markdown files are always underlined.
- Child sessions appear directly under their parent in the sidebar.
- Chats already open in Phlox no longer appear in history, and a deleted chat keeps its name in history.
- Large skills no longer require reselection on every update, which could block sending.
- Session output keeps its order after a restart.
- Settings tiles no longer show the standard focus ring.

## 新機能

- Phlox を終了・更新・再起動しても、セッションの処理が続きます。再び開くと実行中のセッションへ接続し、未回答の承認や質問も表示します。
- グリッドをサイドバーの順に自動で並べられます。自分で並べた配置にも戻せます。
- ペアリング済みの iPhone の名前を変更できます。
- Codex の質問が質問カードで届き、選択肢から回答できます。
- チャットの最上部からさらに引いて離すと、前の履歴を追加で表示します。
- 開始済みのチャットでも、新規チャットと同じモデル・権限・Plan のカードを使えます。

## 修正

- チャットと Markdown ファイルのリンク・開けるファイルに常に下線を表示します。
- サイドバーで子セッションを親の直下に表示します。
- Phlox で開いている会話を履歴の候補に出さないようにしました。削除した会話は削除時の名前で履歴に表示します。
- 大きなスキルを選ぶと、更新通知のたびに選び直しが必要になり送信できなくなる問題を修正しました。
- 再起動後もセッションの出力の順序を保ちます。
- 設定のタイルに標準のフォーカス枠が出ないようにしました。
