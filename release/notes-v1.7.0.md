## New

- Sessions now show a task name, current status, and the destination of your next message. The grid also shows which project and how many sessions are in view.
- Chat makes answers easier to read by keeping processing details collapsible. History entries show clearer names, projects, and last-used times.
- Settings and agent management are easier to navigate, with clearer permission descriptions and model choices.

## Fixed

- Switching views no longer leaves a terminal blank, and terminal text wraps more naturally in team view.
- Model choices have been updated for Claude Code, Codex, and Cursor. Claude's default label follows the installed CLI's model name.
- Slash-command suggestions are restored in non-Codex sessions. Codex model changes through the Control API now take effect, and mobile notifications recover from an invalid device token.

## 新機能

- セッションの作業名・現在の状態・次のメッセージの送信先を確認できるようにしました。グリッドには表示中のプロジェクトとセッション件数も示します。
- チャットでは回答を読みやすくし、処理の詳細を必要なときに開けるようにしました。履歴には分かりやすい作業名、プロジェクト、最終利用時刻を表示します。
- 設定とエージェント管理を探しやすくし、権限の説明とモデルの選択肢を分かりやすくしました。

## 修正

- 表示切替後にターミナルが空白になる問題を修正し、チーム表示でのターミナル本文の折り返しを改善しました。
- Claude Code・Codex・Cursor のモデル選択肢を更新しました。Claude の既定モデル名は、インストール済み CLI の実際のモデル名に追従します。
- Codex 以外で消えていたスラッシュコマンド候補を復旧しました。Control API 経由の Codex モデル変更と、無効な端末トークンからのモバイル通知の回復も修正しました。
